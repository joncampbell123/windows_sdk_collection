How to Install the DirectX Media 6.0 Run Time and Patch

 

Run Time Installation

The Microsoft® DirectX® Media run time, Dxmedia.exe, supports two command-line switches: -NQ and -id:. The required -id: switch must be followed by a unique identifier for the application. The optional -NQ switch enables the user interface. If used, the -NQ switch must come before the -id: switch on the command line, and the letters "N" and "Q" must be capitalized. If the -NQ switch is not used, the installation is totally quiet, and no dialog boxes appear.

 

The following command line provides an example install string.

dxmedia.exe -NQ -id:identifier

 

The identifier should uniquely identify your application. The identifier can be the globally unique identifier (GUID) of your registered application or a unique string. You should not use a string such as “game,” but instead use a more distinctive string.

dxmedia.exe -NQ -id:myrocketgame

  - or -

dxmedia.exe -NQ -id:my_GUID

  - or -

dxmedia.exe -id:my_GUID

 

The identifier is required. If you run Dxmedia.exe without using any switches, or double-click on the Dxmedia.exe icon, the package will display the following message “This package is meant for professional redistribution only” and install nothing.

 

The same syntax is used for all platforms: Microsoft Windows® 9x, Microsoft Windows NT® x86, and Windows NT Alpha. Note that each processor has its own executable (either an Alpha or an x86 version). Windows 2000 does not require the run time as it contains newer files than DirectX Media 6.0.

 

If successful, the installation returns one of the following success codes.

·        ERROR_SUCCESS-installation was successful.

·        ERROR_SUCCESS_REBOOT_REQUIRED-installation was successful, but changes will not take effect until the system is rebooted.

 

If unsuccessful, the installation returns an HRESULT describing the error. A possible error might be E_FAIL, which could indicate a corrupt file.

 

The run time does not check for low disk space. Your setup application should ensure there is enough free disk space before calling Dxmedia.exe.

 

The install package automatically handles different versions during installation. Files are only overwritten if they are older than the files about to be installed.

 

In addition to installing the core DirectX Media run time, the DirectX Media redistributable package installs a minimal version of DirectX Foundation version 3.0 on systems that do not meet the minimum DirectX Media requirements. The application can install DirectX Foundation separately if the full installation is needed after the redistributable package has been installed.

 

Patch Installation

The DirectX Media 6.0 run time patch, dxm6ptch.exe, updates systems containing DirectX Media 6.0 or later to the latest available DirectAnimation and DirectX Transform files. This second version of the run time patch supercedes the original patch that only updated two files (danim.dll and amstream.dll).

 

In addition to updating DirectAnimation and DirectX Transform the patch also fixes the following problem that was found after DirectX Media 6.0 released:

 

Slow video playback of certain video formats when using the DirectShow™ AMStream APIs. The affected video formats depend on the current primary surface type when using multimedia streaming (AMStream.dll). The affected formats are those in which the current primary surface requires a color space transform filter. For example, Indeo 3.2 exhibits the problem while Indeo 5.04 works fine, as do the YV12 or YUY2 formats if they are the current primary surface. AMStreams use the currently available surface format and adjust to it, unlike the video renderer, which tries to create the best surface to suit the video format. This problem did not exist with versions of DirectX Media prior to version 6.0.

 

This patch updates the following files on systems containing DirectX Media 6.0 or later.

The patch automatically handles different versions during installation. Files are only overwritten if they are older than the files about to be installed.

 

If you install this patch from your application, you must install the DirectX Media 6.0 run time (dxmedia.exe) and then queue this patch for installation using the following command line.

dxm6ptch /c:"isv.inf" /Q:A

 

The patch takes effect after the system has been restarted.

 

If you require end users to manually install the patch, no command line switches should be used. The patch performs version checking, notifies the user that it updates DirectX Media 6.0, and will not update systems that do not contain the proper files.
