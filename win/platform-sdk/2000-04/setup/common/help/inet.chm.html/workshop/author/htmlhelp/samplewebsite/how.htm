Designing the HTML Help sample Web site

Our goal in designing the HTML Help sample Web site was to create a site that demonstrates the navigation features available through the HTML Help ActiveX Control. For this example, we also wanted the sample Web site to be similar in appearance to the HTML Help Viewer.

Creating content and navigation files
  • We created HTML topic files, a table of contents, and an index using HTML Help Workshop. The Workshop is a help authoring tool that you get for free when you download HTML Help. We used a Site Map index, which is the recommended index format for uncompiled index files on a Web site.
  • Using HTML Help Workshop, we added the HTML Help ActiveX Control to HTML files to demonstrate the following commands: Close, Contents, Index, Related Topics, Splash, and Version.
  • Using HTML Help Workshop, we inserted the HTML Help ActiveX Control into HTML files and used scripting to demonstrate the following: pop-up messages, and scripting a text link to invoke an ActiveX control command (for an example, see the text link for the sample Version command).
  • We added Related Topics links at the bottom of the main topic files.
  • We added links to the main pages that enable a user to download a compiled help (.chm) file version of the content contained on the Web site.
Creating the frameset
  • We created three frames for our frameset and added the HTML Help ActiveX Control Splash command to the default topic that appears in the right frame. This opens the frameset with a splash screen that explains what you are about to see. We set the splash screen to appear for 5 seconds. You can click anywhere on the screen to close it before 5 seconds. Content loads in the background while a user is viewing the splash screen.
  • We added a banner graphic to the top frame.
  • We added the HTML Help ActiveX Control Contents and Index commands to the Contents and Index navigation topics that appear in the left frame.
  • Using HTML Help Workshop, we edited the table of contents to use Web icons (authors can choose from more than 40 custom icons when creating a table of contents with HTML Help Workshop) for our contents entries.
  • We created a second instance of the default topic without the splash screen, so the splash screen will not appear again if a user navigates back to the default topic while browsing the Web site.

Sound too complicated? We've made it easy for you. Go ahead, use this frameset!

Manipulating the browser
  • We used script inside an HTML anchor tag in all links to the frameset to open Microsoft Internet Explorer. The script uses the open command, which we used to specify an on-screen size and position that is similar to the HTML Help Viewer window.
  • We set Internet Explorer to open method without a toolbar, address box, or menu bar so the user will rely on the HTML Help ActiveX Control for most navigation.
  • We used an anchor tag that contains Javascript at the bottom of the Welcome page to close the instance of Internet Explorer.
