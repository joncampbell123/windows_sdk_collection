Frameset file example

The frameset file contains the <FRAMESET> tag, which enables you to specify attributes for the different frames in your frameset.

Here is the source code for our frameset file:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2//EN">
<HTML>
<HEAD>
<TITLE>Frameset file example</TITLE>
</HEAD>
<FRAMESET ROWS="70, 100%">
<FRAME src="top.htm" name="top" scrolling=no noresize>
<FRAMESET COLS="250,*" frameborder=0>
<FRAME src="toc.htm" name="left" scrolling=auto>
<FRAME src="main.htm" name="right" scrolling=auto>
</FRAMESET>
</HTML>
