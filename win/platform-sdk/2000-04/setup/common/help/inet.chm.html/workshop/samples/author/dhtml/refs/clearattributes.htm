clearAttributes Method Example

This sample uses the clearAttributes method to remove all attributes from an object. Click the View outerHTML button to see the HTML source of the DIV element. When you click the Clear Attributes button, the attributes set on the element are removed and the outerHTML property is displayed. Notice that the onmouseover, onmouseout, and onclick events are not cleared, but the ID attribute and the ATTRIBUTE1 and ATTRIBUTE2 expandos are cleared. Click the Reset Attributes button to return the attributes on the element to their original state.
