IHTMLImgElement::get_border Method

Retrieves the current thickness of the border around the element in pixels.

Syntax

HRESULT get_border(
    VARIANT *p
);

Parameters

p
Address of a VARIANT structure that receives the border thickness.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLImgElement::put_border Method

Sets the thickness of the border around the element in pixels.

Syntax

HRESULT put_border(
    VARIANT v
);

Parameters

v
VARIANT structure that specifies the border thickness to set.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE
