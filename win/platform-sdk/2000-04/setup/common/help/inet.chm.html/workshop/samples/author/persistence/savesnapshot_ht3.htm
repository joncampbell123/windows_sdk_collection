Persisting Form Data

This is a sample trip expense report. When this form is saved to disk, the values in the form fields will be saved with the page. If the form has been validated, a special style will be applied with new controls for the Employer to edit the data.

Once the form has been completed, click the Validate button. This will determine whether or not the form has been completed and will set the persistent script variables. If the form has been validated, save the page as Web Page, HTML Only.

Click the Populate Form button at the bottom of the page to flood the fields with generic information.

No personal or private information should be entered in this form.
