Windows Media Content Creation Authoring Guide

April 7, 1998

Imagine that you could look over the shoulder of a content producer who is discussing and demonstrating all the steps from planning to delivering a cool multimedia presentation using Windows Media Technologies. Well, this is your chance to do just that!

The Microsoft Windows Media Content Creation Authoring Guide, a comprehensive guide to creating stored streaming media content for Windows Media Services, is available for downloading (run ccag.exe to extract the documentation files; the guide is available in both Word .doc and HTML format).

The Microsoft Windows Media Content Creation Authoring Guide provides information on the basics of working with multimedia for beginners, and detailed how-to and technical information for those who want to create streaming media content. It includes ASF files to try out, and lots of great information about getting the most from your audio and video by selecting codecs that are appropriate for your content.
