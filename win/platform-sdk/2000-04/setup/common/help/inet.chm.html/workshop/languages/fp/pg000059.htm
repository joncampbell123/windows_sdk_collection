Microsoft® FrontPage® is the quick, effective way to create and manage professional-quality Internet and intranet sites without programming.

If you're looking for product specifications, system requirements, news and review, or online ordering, you can find that information on the FrontPage Web site. If you can't find something you're looking for on this site, please let us know. We're open to taking suggestions about what FrontPage content to add in the future.

FrontPage has more than a million and a half current users worldwide, and over 600 Web Presence Providers host Web sites created with FrontPage. Web developers commonly use FrontPage to produce and manage Web sites, quickly prototype site designs, find unlinked or duplicate files on their sites, and create Web sites that are then delivered to their clients to maintain.
