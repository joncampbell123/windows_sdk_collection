Web Glossary

February 19, 1999

  • Hinting
    Hinting (or instructing) is a method for preserving the design characteristics of a typeface and producing a quality font. A hint is a mathematical instruction added to a font to distort a character's outline at particular sizes. Hinting defines exactly which pixels in a font are turned on in order to create the best possible character bitmap shape that is still legible at small sizes and low resolutions.
  • HTML 3.2
    Approved as the standard Web publishing language by the World Wide Web Consortium (W3C) in the spring of 1996, HTML 3.2 contains features such as applets, sub- and superscripts, tables, and text flow around images. Backward-compatible with HTML 2.0, every HTML 3.2 document begins with the <!DOCTYPE> declaration that distinguishes it from earlier versions of HTML documents.
  • HTML 4.0
    Approved as a standard by the World Wide Web Consortium (W3C) in 1997, HTML 4.0 contains more text, multimedia, and hyperlink features than previous versions of HTML. It supports in-line frames and framesets, script and object support, enhanced support for forms, compound document enhancements, and enhanced table support. HTML 4.0 also allows greater accessibility on the Web and addresses key internationalization issues, such as representation of international characters, text direction, and punctuation of Web-based documents.
  • HTML element
    A Hypertext Markup Language (HTML) document, or Web page, consists of text marked up with HTML elements, or tags. Elements consist of a start tag (e.g., <H1>), and sometimes, an end tag (e.g., </H1>). Elements have certain attributes that mark up the contents or provide additional information about the enclosed text. HTML elements are used to mark items such as text and graphics in a document to indicate how Web browsers should display these items to the user; elements also indicate user actions, such as mouse clicks.
  • HTML Help
    HTML Help is a set of online technologies for delivering Web and help content with navigational controls that allow users to easily find and sort information. The basic components of HTML Help include HTML content, an ActiveX control, the layout engine, and the HTML Help window.

    The HTML-based content can also include any of the graphic formats currently supported by HTML—as well as other Web technologies, such as Windows Media Technologies, Shockwave, VRML, JScript, VBScript, animation, etc. Utilizing the features of the system, a Web author can create a hierarchical table of contents, as well as keyword and full-text searching within their your Web site.

  • HTTP server
    An HTTP server uses the Hypertext Transfer Protocol (HTTP) to provide information in hypertext format. Clients relay this input from the user to the server and display information on the server in the HTTP format. Microsoft Internet Information Server (IIS) is an example of an HTTP server. Other types of Internet-based servers include File Transfer Protocol (FTP) and Gopher. The Web is a network consisting of all these types of servers.
  • HTX
    See IDC/HTX file
  • Hue
    A hue is a specific position on the visual portion of the electromagnetic spectrum and is the color attribute that most readily differentiates one color from another.

    This attribute is used in the Hue-Saturation-Brightness (HSB) color model. In HSB, hue is the color itself as placed on the color wheel; saturation is the amount of color or intensity in a specified hue; and brightness (or color lightness) is the percentage of white in the color.
