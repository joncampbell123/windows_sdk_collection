Installing the Microsoft® FrontPage® Server Extensions

Microsoft Corporation

Updated April 15, 1999

The FrontPage Server Extensions are installed in two steps. First, the server extensions installation program copies the server extensions into a single FrontPage directory on the host computer's hard disk. Next, the stub versions of the server extensions executable files are installed on the root web of each virtual server on the host computer and, if subwebs exist on the server, on each subweb. During server extension installation, you can specify on which virtual servers you want to install the server extensions.

After the server extensions are copied to a host computer's hard disk, they must be added to each new FrontPage-extended web that is created. On some platforms, this is initiated automatically by the FrontPage client setup program. On other platforms, it must be done as a separate administrative task.
