WexTech is 100 percent committed to supporting and extending Microsoft's new standard in online Help. We are very excited to offer compatible products, including Doc-To-Help and AnswerWorks, and share our expertise in Help authoring by writing the only official guide to Microsoft HTML Help.

Steve Wexler, President of WexTech Systems, Inc.


WexTech — With the forthcoming Doc-To-Help 3.0, users will have the only tool that enables them to create printed manuals, Windows online Help, HTML, and HTML Help, all from a single source. In a world where new technologies are released daily and users have to continually work to keep up, it's refreshing to know that Doc-To-Help will always be there to support the latest technologies and help users through the often confusing learning process. Doc-To-Help will provide a familiar environment in which to get acquainted with the new HTML Help standard while continuing to support earlier Help platforms.

With WexTech's AnswerWorks, the latest addition to the online Help community, users can add a natural language interface to Windows online Help, resulting in faster, more accurate access to any Help system without guessing which terms to use. The forthcoming version will also include support for HTML and HTML Help, enabling Help authors and software developers to add a natural language interface to any of their Help projects, regardless of the platform. AnswerWorks will facilitate combining the two newest, most exciting standards in online Help, natural language technology, and HTML Help.
