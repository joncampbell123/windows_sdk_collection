Channel Wizard

Updated February 3, 1999

Please note: This version of the Channel Wizard requires the Internet Explorer 4.0 final release, which is available from the Internet Explorer 4.0 site . Please download Internet Explorer 4.0 before running the wizard.

The Channel Wizard is a tool that helps you build a channel without having to understand channel definition format (CDF) syntax or other technical details. The Channel Wizard asks you questions about the channel you'd like to build, and generates two code listings based on your input:

  • Code that you can copy and paste into a CDF file to run the channel
  • Code that you can add to your Web site to launch the channel

The wizard also provides Dynamic HTML samples that will allow you to add special effects to your channel pages easily.

Before you run the wizard, please have the following information ready:

  • Title of your channel
  • A brief description of your channel
  • Location of the first page for your channel
  • How often you'll be updating the channel pages
  • 80x32-pixel logo (.GIF or .JPEG format) for the channel bar
  • 16x16-pixel icon (.ICO or .GIF format) for the Internet Explorer Favorites menu, Channels area
  • 460x365-pixel Web page for launching your channel (preview page)

Click to run the wizard below, and type in answers to the questions in each screen. (Please note that the wizard accepts ASCII characters only.)
