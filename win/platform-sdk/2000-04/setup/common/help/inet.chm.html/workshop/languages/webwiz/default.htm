Microsoft Web Wizard SDK

Beta 1 Release

Updated: May 16, 1997

Looking for a way to extend Microsoft® Visual InterDev™ with new capabilities, or build your own stand-alone wizards that can generate complete Web sites for your users? If so, Web wizards may the solution you've been looking for. Using the Web Wizard SDK, you will be able to create wizards that can automate the production of high-quality, fully functional Web sites. Web wizards can generate and publish content ranging from a few lines of static HTML in a page to an entire Web site, potentially containing hundreds of linked static and dynamic pages. Since Web wizards can generate Active Server Pages (ASP files), your wizards can build pages with advanced database connectivity, or hook into packaged applications or ActiveX™ server components running on the server.

The first beta release of the Web Wizard SDK, available for free downloading from this Web site, allows you to create wizards that automatically publish content to a Web server and can create FrontPage™ 97 and Visual InterDev Web projects based on that content. You can create Web wizards using Visual Basic® 5.0 or Visual C++®, and the SDK is loaded with information and samples to get you started quickly. You will also want to check out the Microsoft Design-time Control SDK pages to download and start building these new authoring components that can serve as building blocks for your wizards. The Design-time Control SDK is also available for free downloading today.
