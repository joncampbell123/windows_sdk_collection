Colors by Saturation

The table below provides a list of the X11 colors supported by Microsoft® Internet Explorer 3.0 and Netscape Navigator. The two color swatches on the left illustrate setting the background color of a table cell in two ways: The first column uses the named color value, and the second column uses the numeric color value. For example:

<tr><td bgcolor="aliceblue" width=15></td>

<td BGCOLOR="#F0F8FF" width=15></td>

 

This allows you to see what the color looks like using both methods.

To set the size of the color swatch cell, I'm using a fully transparent GIF image and setting the ALT text to the color used for that cell. If you're using Internet Explorer 3.0, when your mouse cursor hovers over the cell, a tooltip will pop up, telling you the color value.

The table below is ordered numerically by saturation, but I've also created three additional tables that list the colors sorted by:

  • Lightness
  • Hue
  • Name

 

For a more detailed write-up on named colors, see my article Using Named Colors in Internet Explorer.
