saveFavorite Behavior

This is a sample of the saveFavorite behavior. This sample will demonstrate how persistence can be used to preserve information after saving the page as a favorite.

Enter a value and save this page as a favorite. When you return to this page, the information identified as persistent will have remained, and the information identified as non-persistent will have been reset.

Favorite Frosty Beverage: Persists
Annoying Kitty Names: Tries to persists, but won't
Deepest, darkest secret: Doesn't Persist
