TABINDEX Sample

This sample demonstrates the implementation of the TABINDEX attribute. Press the TAB key or click one of the list items. When setting the TABINDEX attribute in Internet Explorer 5, supported elements also can have focus. The backgroundColor property is set when the list item gets or loses focus.
