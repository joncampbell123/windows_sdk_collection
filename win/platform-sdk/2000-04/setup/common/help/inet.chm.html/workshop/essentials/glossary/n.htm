  • Named colors
    There are two ways in which a color can be specified in HTML code: the hexadecimal equivalent of its Red-Green-Blue (RGB) value (e.g., "#FF99CC"), or by its color name (e.g., "maroon"). There are currently 140 colors that can be referenced by name on HTML pages—the 16 colors in the VGA color set and the X11 color names. The 16 colors in the VGA color set can always be correctly rendered, regardless of the resolution of the user's display card. The X11 colors were originally recommended by the World Wide Web Consortium as part of a standard Cascading Style Sheet implementation and provide an interesting mix of colors, such as CornflowerBlue and LawnGreen. See Using Named Colors in Internet Explorer for a detailed explanation and complete list of named colors.

  • Windows Media Technologies
    Microsoft Windows Media Technologies is an open software platform for streaming multimedia over virtually any type of network, from low-bandwidth dial-up Internet connections to high-bandwidth local area networks. Utilizing the integrated architecture of DirectX, Windows Media Technologies allows Web developers to integrate live and on-demand audio, video, and illustrated audio (synchronized sound and still images) into a Web site or Web application. In addition to supporting Advanced Streaming Format (ASF) files, Windows Media Technologies enable RealAudio® and RealVideo® content to be created, served, and played live or on demand. Windows Media Technologies can access over 95% of the streaming media content on the Web.
