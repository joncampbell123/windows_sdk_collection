Contacting Us

Microsoft Corporation

October 1998

Customers can receive support for Microsoft Agent by calling 1-800-936-5800 (this is the developer support phone line). If you are an MSDN member, you can use one of your MSDN support incidents for this support. If you are not an MSDN member, you can choose the "pay-per-incident" option. You can also submit questions electronically through the Support Web site (this is also pay-per-incident unless you already have a support contract with us).

For reporting bugs, please use the bug report form.

For information on licensing and distributing Microsoft Agent, see Licensing and Distribution.

To contact the community of active Microsoft Agent developers, visit the public newsgroup: microsoft.public.msagent. Note that Microsoft does not actively monitor this peer-to-peer support forum.
