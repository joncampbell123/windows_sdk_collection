Are Your Class Names Not Working?

.1 {color:#0000FF; font-size:24px; font-family:Verdana}

This sentence has a numeric class name of .1 and is not inheriting style in Netscape Navigator 4.x, but does in Internet Explorer 4.0.

.p1{color:#0000FF; font-size:24px; font-family:Verdana}

This sentence has a class name of .p1.
and it displays in blue, 24px, Verdana in both Internet Explorer 4.0 and Netscape Navigator 4.x.

Solution: To be safe, don't start your class names with a number or a dash; use alpha or alphanumeric class names.
