DetectEncodingInfo Structure

Contains the results of code page detection by the IMultiLanguage2::DetectCodepageInIStream and IMultiLanguage2::DetectInputCodepage methods.

Syntax

typedef struct tagDetectEncodingInfo{
    INT nLangID;
    INT nCodePage;
    INT nDocPercent;
    INT nConfidence;
} DetectEncodingInfo, *pDetectEncodingInfo;

Members

nLangID
Win32®-defined primary language identifier that has been detected for the source string.
nCodePage
Win32-defined code page (valid for single-byte and double-byte input only) that has been detected for the source string.
nDocPercent
Percentage of the string that is in the detected language.
nConfidence
Integer indicating the degree to which the detected data is correct. Confidence is based on an internal scoring method. It is a relative cumulative data item rather than an absolute percentage; therefore, values may be greater than 100.
