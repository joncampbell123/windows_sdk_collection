Valid values

Syntax Description
<PARAM name="Command" value="command name [,menu|,dialog [,popup]]"> Specifies the command to invoke.

The ALink, KLink, and Related Topics commands include a setting ([,menu|,dialog]) that specifies whether to display target topics on a pop-up menu or in a dialog box.

The WinHelp command includes a setting ([,popup]) that specifies the window type in which to display the specified WinHelp topic.

Multiple Command parameter values are delimited by a comma.
