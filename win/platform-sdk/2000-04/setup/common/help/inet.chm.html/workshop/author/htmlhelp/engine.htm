Bring the Power of the Web to Your Help System

Microsoft Corporation

June 23, 1998

HTML Help is the first help compiler to take full advantage of the advances in content and graphics display, styles, scripting, and redistributable components made possible by the Internet. The HTML Help Viewer hosts the HTML Help Layout Engine (Shdocvw.dll), which is started either directly through the HTML Help API or indirectly through the HTML Help executable program. You can also create a program that hosts the layout engine. This gives help authors the options and flexibility of Web designers.

The HTML Help Layout Engine renders input from the same sources as the browser. This gives you the capability to use HTML, ActiveX® Controls, Java applets, scripting, and multimedia in your help topics. With the release of Microsoft® Internet Explorer 5.0, you can use Dynamic HTML in your files to render information. Sound, animation, and video can also be part of your help system.
