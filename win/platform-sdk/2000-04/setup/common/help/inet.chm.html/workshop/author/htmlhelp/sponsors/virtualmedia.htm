Virtual Media is excited by the new documentation features available in HTML Help. Through our authoring tool, HDK, authors will be able to seamlessly migrate to this new medium.

Calvin Rowley, President of Virtual Media Technology


Virtual Media Technology — HDK and its add-on modules are already compatible with HTML Help. And because HDK gives you true single sourcing, you can simply select the HTML Help compiler and your Help project is automatically ported to this exciting new medium. HDK ensures your project's design and features are faithfully reproduced in HTML Help.

HDK also offers authors many extended features such as electronic forms, a Java table of contents system, graphical buttons, animations, symbols, project management, and hundreds more features. Plus, HDK gives you a single source for paper manuals through other forms of HTML and traditional WinHelp advanced. Take a look at HDK and start using HTML Help now!
