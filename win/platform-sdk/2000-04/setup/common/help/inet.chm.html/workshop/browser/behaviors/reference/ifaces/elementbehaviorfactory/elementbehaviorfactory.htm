IElementBehaviorFactory Interface

This interface provides a standard mechanism for MSHTML to locate and instantiate a Dynamic HTML (DHTML) behavior.

IElementBehaviorFactory Methods

FindBehavior Requests that the specified DHTML behavior be instantiated.

Interface Information

Implementation Mshtml.dll
Inherits from IUnknown
Header and IDL files Mshtml.idl, Mshtml.h
Minimum availability Internet Explorer 5
Minimum operating systems Windows 95, Windows NT 4.0

Remarks

MSHTML attempts to locate and instantiate a DHTML behavior when it locates a reference to the behavior during the parsing of an HTML document.

MSHTML initially calls the host application's IServiceProvider::QueryService interface, specifying the SID_SHTMLElementBehaviorFactory identifier, to request the IElementBehaviorFactory interface. The hosting application provides this service through its client site.

If the IElementBehaviorFactory interface is available, MSHTML calls the IElementBehaviorFactory::FindBehavior method to instantiate the DHTML behavior. If successful, this method returns an IElementBehavior interface.

If the DHTML behavior is not available, MSHTML queries the OBJECT elements on the page to see if they implement the DHTML behavior.

The component object that implements the IElementBehaviorFactory interface must be safe for scripting and persistence.

For more information about signing a DHTML behavior component object, see Signing Code with Microsoft Authenticode Technology.

For more information about using the IObjectSafety interface to identify a DHTML behavior component object as safe for scripting, see Supporting the IObjectSafety Interface.
