Web Wizard Documentation

Beta 1 Release

May 1997

The Web Wizard documentation explains how to use the Web Wizard SDK for constructing wizards using Microsoft® Visual Basic® 5.0. Although you can use other development tools, such as Microsoft Visual C++®, to build wizards, Visual Basic 5.0 and the Web Wizard SDK provide significant productivity advantages over these other tools. You can design and construct four types of wizards that will run within your Visual InterDev™ application or will operate on their own.

Two introductory chapters from the SDK documentation are available on this site in HTML format:

  • Wizards You Can Build
  • SDK Components

The complete documentation is provided in zipped Word format below and includes the following additional sections:

  • Setting Up the Web Wizard Development Toolkit
  • Designing Your Wizard
  • Building a Wizard in Visual Basic 5.0
  • Building a Stand-Alone Wizard
  • Appendix A, Wizard Object Model
  • Appendix B, Common Wizard Tasks
  • Appendix C, Registering Wizards
  • Appendix D, Handling Navigation Through the State Table
  • Appendix E, Your Wizard Working in the Background
  • Appendix F, Building a Wizard Manually
