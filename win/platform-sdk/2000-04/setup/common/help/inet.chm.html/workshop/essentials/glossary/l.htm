  • Localization
    Localization is the process of adapting a Web site or program so it is appropriate for the area, or locale, for which it is used. In an international market, this means translating the user interface and the content, resizing dialog boxes to accommodate varying character amounts, customizing features (if necessary), and testing the results to ensure the site or program still functions correctly. (See also: Globalization)
