Set Up the HTML Help Installation and Update Package

Microsoft Corporation

Updated: March 30, 1999

There are 28 language versions (including English) of the HTML Help Installation and Update package (Hhupd.exe, version 1.21). In the table below, download the package by selecting the language version you would like for your platform.

Notes

  • The HTML Help Installation and Update Package (any language version of Hhupd.exe) will not run on a Windows NT system unless you have administrator privileges.
  • If you are using an Intel processor, choose a file from the left column. If you are using the Alpha (RISC) processor, choose a file from the right column.
  • Developers working on the Alpha (RISC) platform should download the Alpha version of htmlhelp.lib. If prompted, save the file to disk.
