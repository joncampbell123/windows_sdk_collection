onkeydown Sample

This sample demonstrates the implementation of the onkeydown event. As of Internet Explorer 5, most keys that fire the onkeydown event are cancelable.

Type some text into the field. If the check box is checked, the key strokes do not show up in the text field, and "[trap]" is displayed in the TEXTAREA element. If the check box is not checked, the key strokes are displayed in both the text field and the TEXTAREA element.
