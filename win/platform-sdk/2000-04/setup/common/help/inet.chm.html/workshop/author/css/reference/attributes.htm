CSS Attributes Reference

This section defines the supported cascading style sheets (CSS) attributes. An asterisk (*) indicates the attribute is available as of Microsoft® Internet Explorer 5 or later. If an attribute or property has been proposed to the World Wide Web Consortium (W3C) but not yet made standard, it is marked as "proposed."
