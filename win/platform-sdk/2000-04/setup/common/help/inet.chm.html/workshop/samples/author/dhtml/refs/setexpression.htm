setExpression Method Sample

This sample uses the setExpression method to update the innerText properties of table rows. When the page loads, expressions are added to every table row except the first and the last. The uniqueID property is used to pass a reference to each row that has an expression.

You can change the prices and quantities by clicking on the blue table cells. When you enter a new value, the expressions for the totals update immediately.
