IDocHostUIHandler::ResizeBorder Method

Called from the MSHTML implementation of IOleInPlaceActiveObject::ResizeBorder.

Syntax

HRESULT ResizeBorder( 
    LPCRECT prcBorder,
    IOleInPlaceUIWindow FAR *pUIWindow,
    BOOL fFrameWindow
);

Parameters

prcBorder
Address of the new outer rectangle for border space.
pUIWindow
Address of the frame or document window whose border is to be changed.
fFrameWindow
Boolean value that is TRUE if the frame window is calling ResizeBorder, or FALSE otherwise.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
