IMachineDebugManagerCookie Interface

This interface maintains a registry of debuggable application processes with debug cookie support.

IMachineDebugManagerCookie Methods

AddApplication Adds an application to the list of running applications.
EnumApplications Enumerates the running applications.
RemoveApplication Removes an application from the list of running applications.

Interface Information

ImplementationCustom
Inherits fromIUnknown
Header and IDL filesActivdbg.h, Activdbg.idl
Minimum availabilityInternet Explorer 4.0
Minimum operating systemsWindows 95, Windows NT 4.0
