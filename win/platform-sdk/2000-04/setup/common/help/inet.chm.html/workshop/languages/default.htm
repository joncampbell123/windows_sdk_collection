Languages & Development Tools

The Languages and Development Tools section contains information on such topics as scripting, Java, Microsoft JScript™, and Microsoft FrontPage.

Scripting

The Languages and Development Tools section hosts the series Clinick's Scripting Clinic, authored by Andrew Clinick. Each article covers a different scripting issue, such as whether to use VBScript or JScript and Y2K issues.

Microsoft FrontPage

This extensive collection of information includes tutorials for both FrontPage 2000 and FrontPage 98, as well as many articles on topics of Web design and development using Microsoft FrontPage. You'll also find some helpful links to articles on FrontPage Server Extensions.

Languages

You'll also find information on Java, from the C++ developer's perspective, the Microsoft Script Debugger for Internet Explorer, and error handling in Microsoft JScript®.
