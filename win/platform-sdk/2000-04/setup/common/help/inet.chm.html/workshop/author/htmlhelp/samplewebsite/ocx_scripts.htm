About the HTML Help ActiveX Control and scripts

You can add functionality to one or more HTML files using the HTML Help ActiveX control in conjunction with a scripting language such as Visual Basic Scripting Edition or JScript.

For example, if you want to implement pop-up messages that appear when a user completes a specific action, such as clicking a hyperlink, you could write a small amount of script code to call the the HTML Help ActiveX control method TextPopup.

To access an instance of the HTML Help ActiveX control from a script, you first need to insert the control into an HTML file and provide a unique ID for it. You specify the ID in your script. Generally, your script will pass all necessary parameters to the control, which allows you to omit the <PARAM> tag when you insert the HTML Help ActiveX control into your file.

The following example is an "open" instance of the HTML Help ActiveX control that can be accessed by a script:

<OBJECT id=for_script type="application/x-oleobject"
classid="clsid:adb880a6-d8ff-11cf-9377-00aa003b7a11"
>
</OBJECT>

All parameters are passed to the HTML Help ActiveX control through script code.

Note

  • If you do not specify the width and height parameters, the default size is used (100x100 pixels).
