This paragraph has a class that references a STYLE defined in this document's head, and is followed by an INPUT control. When you click the Set disabled to true button, the STYLE object's disabled property is set to true, and the rules cease to apply. The INPUT control's disabled property is also set to true and becomes inaccessible. But don't worry, the disabled property can be set to false, making both the rules and the INPUT button accessible again.
