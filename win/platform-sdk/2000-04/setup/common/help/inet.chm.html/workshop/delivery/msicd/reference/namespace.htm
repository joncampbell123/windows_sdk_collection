NAMESPACE Element

Defines a private namespace for stand-alone Java applications.

Syntax

<NAMESPACE>
    string
</NAMESPACE>

Element Information

Number of occurrences None or one
Parent elements JAVA
Child elements None
File formats supported OSD
Requires closing tag Yes
