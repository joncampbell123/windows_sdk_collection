setTimeout | setInterval Demo

The following steps illustrate a simplified use of setTimeout and setInterval. Once you've specified the desired method, argument convention, and a timeout interval, clicking "Go" will set a timer. When the interval expires a callback function will be invoked, and the title of this document will be modified.

In the case of setTimeout, the callback function will be invoked only once. In the case of setInterval, the callback function will be invoked repeated until the timer is cleared.

Click the "clear interval" button to clear the timer

Note that while the documentation states that the callback function can be passed as a string, the callback function will not be invoked unless the callback function is passed as a function pointer. My tests show that this is true in IE4 and IE5.

  1. Specify one of the following methods:
    setTimeout setInterval
  2. Pass the callback function as one of the following:
    String Function Pointer
  3. Specify an interval in milliseconds (minimum of 15)
  4. Click "Go" to start the timer.
