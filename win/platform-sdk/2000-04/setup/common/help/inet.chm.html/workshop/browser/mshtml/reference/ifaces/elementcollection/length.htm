IHTMLElementCollection::get_length Method

Retrieves the number of objects in the collection.

Syntax

HRESULT get_length(
    long *p
);

Parameters

p
Address of a long integer variable that receives the number of elements in the collection. For details, see the length property.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLElementCollection::put_length Method

Sets the size, in objects, of the collection. This method works only on area elements and options.

Syntax

HRESULT put_length(
    long v
);

Parameters

v
Long integer value that specifies the number of elements. For details, see the length property.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
