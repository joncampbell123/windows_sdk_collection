Windows Media Technologies Branding and Logos

Updated April 14, 1999

Branding

In connection with the Windows Media Technologies 4.0 releases, Microsoft has rebranded its streaming media technologies as follows:

  • The streaming media platform as a whole is named Windows Media Technologies.
  • The player is named Windows Media Player; cross platform versions are named Microsoft Media Player.
  • The streaming media services in Windows NT Server are named Windows Media Services.
  • The broadcast-quality video server continues as the Microsoft NetShow Theater Server.
  • The content creation tools are named Windows Media Tools.
  • The partner/provider program is now called Windows Media Service Provider Program.
  • The SDK is named Windows Media Services SDK.
  • The file format created by the Windows Media Tools and third-party compatible tools is named Advanced Streaming Format, or ASF.

Here are some examples of how you may refer to the Windows Media technologies on your Web site.

  • "Content served by Windows Media Services."
  • "You can access content in the ASF format using the Microsoft Windows Media Player."
  • "You can use either Netscape Navigator or Microsoft Internet Explorer browsers with the Windows Media Player to view content served by Windows Media Technologies."
  • "Click here to download the Windows Media Player."

New Logos Available

As part of the branding change, we are providing you with two new logos and a new download URL that you can use to provide your end users with the best possible streaming media experience when they access your site:

A new Get Windows Media Player download logo that you should use to assist end-users in downloading the player. This logo points to a new, "intelligent" download page on www.microsoft.com that simplifies and automates the installation of the Windows Media Player. See http://msdn.microsoft.com/community/osig/wm/getwmp.asp to get the logo and to see the instructions for proper usage.

A new Best Experienced with Windows Media Player logo that you should use to indicate that streaming media content on your site utilizes Windows Media Technologies and meets all the following criteria:

  • In ASF format
  • Encoded using Microsoft-supported codecs

See http://msdn.microsoft.com/community/osig/wm/wmsins.asp for the logo, instructions for proper usage, and license agreement for using the logo.
