Author Files Using HTML Help Workshop

Microsoft Corporation

April 6, 1999

Microsoft® HTML Help Workshop is an executable program (Hhw.exe) you use to create help systems with source files based on Hypertext Markup Language (HTML). With HTML Help Workshop, you can create help systems for distribution on 3.5-inch disks, compact discs, or Web sites.

With its easy-to-use interface, HTML Help Workshop allows you to organize the different files that make up content of your help system into a single project (.hhp) file, and to author HTML files with a text editor. You can also create and edit contents (.hhc) and index (.hhk) files, add graphic (.gif, .jpeg, .png) files, and insert the HTML Help ActiveX® control into your HTML files.

Whether you are creating an HTML Help system or a Web site that uses the HTML Help ActiveX control, you can view this content with the Help Viewer or in any browser that supports ActiveX technology, such as Microsoft Internet Explorer (version 3.01 or later).
