Example of the setData Method

This example demonstrates how to use the setData and getData methods of the dataTransfer object to enable the source path of the image to be dragged.

  • To view the source path of the image, drag the image and drop it over the SPAN that says, "drop the image here."
  • To create a shortcut to the image, drag the image to another application or to the desktop.
