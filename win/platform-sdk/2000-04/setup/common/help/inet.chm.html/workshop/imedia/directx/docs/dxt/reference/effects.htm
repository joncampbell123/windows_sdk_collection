DirectX Transform Transitions and Filters

February 15, 1999

The following list shows the Microsoft® DirectX® Transform transitions and filters that you can use with Microsoft DirectAnimation™. Note that to use most of these transforms you must have DirectX Media 6, Microsoft Internet Explorer 5, the Microsoft Windows® 98 OEM Service Release (OSR), or Windows 2000 installed. To use the Chroma filter or the DropShadow filter, you must have Internet Explorer 5, the Windows 98 OSR, or Windows 2000 installed.
