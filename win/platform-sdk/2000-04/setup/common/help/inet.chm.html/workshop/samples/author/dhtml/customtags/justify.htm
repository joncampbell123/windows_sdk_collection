Justifying Text


This paragraph demonstrates sample usage of the custom <MY:JUSTIFY> tag in a document. By wrapping the paragraph in start and end <MY:JUSTIFY> tags, the contained text is justified within the specified width. Try resizing the window to verify that the content is justified within a 500-pixel width. And don't forget to right-click anywhere on the window and "View Source".
