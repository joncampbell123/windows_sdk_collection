The HTML Help sample Web site


Welcome!  This Web site was created to demonstrate the functionality of the Microsoft® HTML Help ActiveX™ control. The latest version of the HTML Help ActiveX control reference is used for its sample content. This reference is also available in the main documentation.

You can use the HTML Help ActiveX control to provide a table of contents, an index, related topics, and other navigation features to your Web site. One advantage of using HTML Help is that it enables authors to update content on the Web in between scheduled software releases of online help.

The same topics used in this Web site can be viewed in a compiled help (.chm) file.

Download a compiled help file version of this reference.

Note   The HTML Help ActiveX control uses the underlying components of Microsoft Internet Explorer to display content.
