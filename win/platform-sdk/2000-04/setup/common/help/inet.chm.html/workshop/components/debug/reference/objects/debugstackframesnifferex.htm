DebugStackFrameSnifferEx Object

This object provides a means for enumerating logical stack frames for a given component.

ImplementationCustom
Header and IDL filesActivdbg.h, Activdbg.idl

Creation/Access Functions

Interfaces Implemented

IDebugStackFrameSnifferEx This interface is an extension of the IDebugStackFrameSniffer interface and provides a means for enumerating logical stack frames.
