mergeAttributes Method Example

This sample uses the mergeAttributes method to copy attributes, styles, and events from one element to another. Click the View outerHTML button to see the HTML source of the second DIV element. When you click the Merge Attributes button, the attributes, styles, and events set on the first DIV element are copied to the second DIV element, and the outerHTML property is displayed. Notice that the ID is not copied, but the ATTRIBUTE1 and ATTRIBUTE2 expandos and events are copied. Click the Reset Attributes button to return the attributes on the element to their original state.
