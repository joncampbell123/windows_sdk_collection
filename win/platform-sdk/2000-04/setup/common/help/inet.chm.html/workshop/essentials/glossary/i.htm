  • IDC
    See IDC/HTX file
  • IDC/HTX file
    An IDC is a core component of Microsoft Internet Information Server (IIS). It provides database connectivity between IIS applications and any ODBC-compliant database. An HTX (HTML extension) file is a standard HTML file containing some additional tags that enable IIS and Index Server to include variable names and other processing capabilities. The HTX file is used as a template to format the results. Combining the qualities of IDC and HTX, a user's table, query, or form datasheet can be saved as an IDC/HTX file that generates HTML documents by querying a copy of the user's database located on the Web server. Unlike static HTML documents, IDC/HTX files generate an HTML page with current data from the database; the HTML documents that are generated are called dynamic. IDC/HTX files are usually used with programs such as Microsoft Access.
  • Illustrated audio
    Illustrated audio is a stream that combines audio with synchronized images to create online slide shows that run at low bandwidths.
  • Image map
    An image map is an image on a Web page that contains more than one hyperlink. When a user clicks on different areas on the specially formatted graphic, "hot spots" are triggered, and the user is linked to another part of the Web page, a different Web page, or a file. The locations of the hot spots are specified using pixel coordinates in a map file, which is stored on the server.
  • Index Server
    See Microsoft Index Server
  • Internet Engineering Task Force (IETF)
    The IETF a is protocol engineering and development organization engaged in the development of new Internet standard specifications, with the goal of creating an open Internet standard for identifying online presence. Comprised of a large, open international community of network designers, operators, vendors, and researchers concerned with the evolution and development of the Internet, the IETF is now under the sponsorship of the Internet Society .
  • Internet Information Server (IIS)
    Microsoft IIS is a high-performance, secure, and extensible Internet server which enhances the functionality of Windows NT Server 4.0. IIS 4.0 is installed as a component of the Microsoft Windows NT 4.0 Option Pack. A complete set of tools for building server-based Web applications (Weblications) is included in IIS. Another important feature of IIS is its Active Server Pages capability, which allows Web authors to combine HTML, server-side scripts, and ActiveX controls.
  • Internet Locator Server (ILS)
    See Microsoft Internet Locator Server (ILS)
  • Internet Services Application Programming Interface (ISAPI)
    ISAPI is a high-performance application-programming interface (API) for back-end applications for Microsoft Internet Information Server. A server-side interface, ISAPI offers significant performance advantages over the Common Gateway Interface (CGI), because it has its own dynamic-link library.
  • ISAPI
    See Internet Server Application Program Interface
