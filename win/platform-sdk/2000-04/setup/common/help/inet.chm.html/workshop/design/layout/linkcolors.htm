Link Color Combinations

Choose combinations from the 216 browser safe colors. I have charted some of my favorites combinations below, but there remains hundreds of choices. Other options to consider are:

  • just change the color of the ALINK, and set the link and visited link to the same color
  • set the mouse over color to a strong contrasting color
  • just change the visited link color, keep the active and link colors the same

I recommend reading and using Lynda Weinmans book entitled Coloring Web Graphics to help you choose complimentary color combinations that will work with your site design.
