About Commands

Microsoft Corporation

Updated June 10, 1999

The Command parameter supports a set of values, known as commands. Each value specifies an action for the HTML Help ActiveX control to carry out. Most of the commands require that you specify additional parameters that determine exactly how to carry out the action.

Use the commands to add functionality to a compiled help (.chm) file or a set of uncompiled HTML files. For example, the Contents command adds a graphical table of contents to your help system based on a contents (.hhc) file that you specify.

Notes

  • All of the commands are available in HTML Help Workshop through the HTML Help ActiveX Control Wizard. The wizard guides you through the process of inserting the HTML Help ActiveX control in a file.
  • Only one command can be specified in any single instance of the control.
  • A command should be located in an HTML file exactly where you want the feature to appear.
