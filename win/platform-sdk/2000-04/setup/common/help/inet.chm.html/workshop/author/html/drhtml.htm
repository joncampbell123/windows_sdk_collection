Doctor HTML

June 25, 1996

As many Webmasters can testify, maintaining and updating a Web site can be a tedious and time-consuming process. A great deal of time can be spent searching for flaws that damage a document's impact. Imagiware has developed an online tool, Doctor HTML, which identifies many common Web page problems, making the task of site administration much easier.

Doctor HTML is a Web page analysis tool that loads your page over the Internet and provides suggestions on how to improve your document. Incorrect HTML, spelling mistakes, broken hyperlinks, and missing images can all reduce the best designed pages to a jumbled mess. Here is a summary of the tests that Doctor HTML performs on a Web page:
  • Document structure: Doctor HTML searches the document for errors in the HTML that may cause a problem when the page is displayed. Since many mistakes will only appear in certain browsers, and may be overlooked when the Web page is created, it is crucial to detect these errors to ensure consistent performance.
  • Spelling mistakes: One of the most common oversights in Web page design is failure to check for misspelled words. Few mistakes can make a Web page look more unprofessional than incorrect spelling.
  • Broken hyperlinks: Since the Web is a dynamic medium, hyperlinks quickly become out-of-date. Doctor HTML eliminates the time-consuming task of verifying hyperlinks by returning a list of invalid links based on the server's response.
  • Image tests: While images assist in the attractive design of any page, careful choices must be made to ensure optimal performance over the Internet. Doctor HTML examines the images embedded in a Web page, and estimates how long a viewer must wait before all the images are displayed. It also looks for the existence of HTML tags that can facilitate the fast loading and display of the document.

With the help of Doctor HTML, Web designers can efficiently create and administer a site, ensuring optimal performance for the viewer. The single page service is freely available at http://imageware.com/RxHTML/ , with advanced features such as the Site Doctor available by subscription.
