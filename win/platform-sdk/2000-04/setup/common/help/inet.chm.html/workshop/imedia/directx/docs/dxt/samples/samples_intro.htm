Transform Samples

Sample Description
Basic Transform Sample This is a very short sample, which uses the Wipe transform to cycle back and forth between images.
Image Cycling Sample This sample shows how to create a sequence of images that uses the Slide transform to smooth the transitions between images.
Single Transition Slide Show This sample shows how to create a sequence of images that uses the Fade transform as a transition for a picture slide show.
Multiple Transition Slide Show This sample is much like the other slide show sample, but it uses a different transform for each transition.
