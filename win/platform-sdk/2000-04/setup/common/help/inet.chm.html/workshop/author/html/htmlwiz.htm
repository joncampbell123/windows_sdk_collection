Download (self-extracting) HTML Wizard sample files (147K).

HTML Wizard is a simple but useful tool that adds functionality to the Microsoft® Windows® 95 interface for HTML files. Specifically, HTML Wizard adds:
  • An Edit item to the Context menu (right-button click) for HTML files. This option will allow you to launch your favorite HTML browser and load in that file.
  • An HTML Document option to the list of file types under the Windows 95 Explorer File New option. This option will create a base (that is, minimum) HTML document.
HTML Wizard was built using Microsoft Visual C++™ version 4.0, the Win32® SDK, and the Internet Information Server SDK.
