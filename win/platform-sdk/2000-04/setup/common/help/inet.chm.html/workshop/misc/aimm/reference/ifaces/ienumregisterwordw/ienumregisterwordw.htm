IEnumRegisterWordW Interface

This interface provides access to the object that enumerates the register strings. Unicode implementation.

IEnumRegisterWordW Methods

Clone Creates another enumerator that contains the same enumeration state as the current one.
Next Retrieves the specified number of REGISTERWORDW structures in the enumeration sequence.
Reset Resets the enumeration sequence to the beginning.
Skip Skips over the specified number of REGISTERWORDW structures in the enumeration sequence.

Interface Information

Implementation Register Word Enumeration Object
Inherits from IUnknown
Header and IDL files Dimm.h, Dimm.idl
Minimum availability Internet Explorer 5
Minimum operating systems Windows 95, Windows NT 4.0
