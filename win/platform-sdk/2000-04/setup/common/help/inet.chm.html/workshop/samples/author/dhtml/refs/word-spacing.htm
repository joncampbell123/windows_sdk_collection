word-spacing Attribute | wordSpacing Property sample

This sample demonstrates the use of the wordSpacing property. The word-spacing attribute is set on a SPAN object with a value of 10. Select a new value from the drop-down menu to change the word-spacing.

The word-spacing attribute is only supported on the Macintosh.
