P Element | P Object

Denotes a paragraph.

HTML Syntax

<P
    ALIGN=CENTER | LEFT | RIGHT | JUSTIFY
    CLASS=classname
    ID=value
    LANG=language
    LANGUAGE=JAVASCRIPT | JSCRIPT | VBSCRIPT  | VBS 
    STYLE=css1-properties
    TITLE=text
    event = script
>

Remarks

The P element is a block element and does not require a closing tag.

This element is available in HTML as of Microsoft® Internet Explorer 3.0, and in script as of Internet Explorer 4.0.

Example

This example uses the P element to create a paragraph.

<P>This is a paragraph.</P>
