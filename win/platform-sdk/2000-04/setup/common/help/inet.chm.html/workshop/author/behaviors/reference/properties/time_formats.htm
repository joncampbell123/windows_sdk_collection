Time Formats

The following table lists the possible formats for expressing time values.

Format Description Examples Supported by
h:min:s.f h = hours
min = minutes
s = seconds
f = fraction of a second		 "03:45:10" = 3 hours, 45 minutes, 10 seconds
"10:35" = 10 minutes, 35 seconds
"10.5" = 10 and a half seconds
"1:00.375" = 1 minute, 0.375 seconds
 begin, clipBegin, clipEnd, dur, end, repeatDur, syncTolerance
number[h | min | s | ms] h = hours
min = minutes
s = seconds (default)
ms = milliseconds 		"3h" = 3 hours
"20min" = 20 minutes
"3.5s" or "3.5" = 3 and a half seconds
"25ms" = 25 milliseconds 		begin, dur, end, repeatDur, syncTolerance

Note that signed clock values (+ or -) are also legal. All clock values are assumed to be positive (+) by default.
