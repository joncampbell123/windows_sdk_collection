Display Topics in the Help Viewer

Microsoft Corporation

June 23, 1998

HTML Help comes with a fully functional HTML Help Viewer in which authors creating help files for distribution on a 3.5-inch disk or compact disc can display their files.

You can use HTML Help Workshop to add buttons and other design elements to the Help Viewer, customizing it to suit your needs. Unless you design your own set of windows or frames to display your help content, the Help Viewer is the default for all help projects. Any topics you add to your help project file will open in the Help Viewer.

The Help Viewer contains three panes:

  • Users view help topics in the Topic pane.
  • To the left of the Topic pane is the Navigation pane, which can be set up to display a table of contents, an index, and a full-text search tab.
  • A third pane contains the toolbar, which allows users to display or hide the Navigation pane, or move forward to the next topic or back to the previous topic. Stop, Refresh, Locate, and Home buttons are also available.

Help authors can customize the Help Viewer by changing its default characteristics. A help file that contains topics on how to use the Help Viewer is available for redistribution.
