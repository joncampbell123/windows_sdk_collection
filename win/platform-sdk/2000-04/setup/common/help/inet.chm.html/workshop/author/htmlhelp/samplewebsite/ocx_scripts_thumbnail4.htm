To add each graphics file to your project file

  1. Open a project (.hhp) file, and then click Add/Remove Topic Files.
  2. In the Topic files box, click Add.
  3. In the File name box, type the name of the graphics file, and then click Open.
  4. Repeat steps 2 and 3 for each graphics file you need to reference, including thumbnail files, if they have different file names.

Notes

  • This ensures that the graphics files will be compiled with the rest of the files in the project.
  • The graphics files should reside in the same directory as the project file.
