Color Questions and Answers

What I'm wondering is whether or not one saves any appreciable download time when one utilizes the same palette across the board on all images on a Web site? You know, regardless of whether it's Internet Explorer's or Netscape's or my own particular palette.

I think I need to know whether or not an image file re-accesses or re-processes that universal palette when that image file loads, or does it go, "Oh, Palette Number One? I've already GOT that thanks!" and move on...... If it only needs that palette once per site visit, no matter how many pages or images the visitor loads... that could mean some substantial speed gains.

Thanks in advance!
Steve Zich

The Experts' Answer:

Download time is determined by file size. Most of the size of the file is set by the bit-depth and resolution of the image and compression scheme such as 8-, 16-, 24-bit or compressed JPEG.

For example, an 8-bit, uncompressed image at 640x480 would require about 300K bytes. A custom palette associated with that file, assuming 216 Windows-allowed colors, would occupy only about 648 bytes (216 entries times 3 bytes per color).

Therefore, using the same palette would only compromise quality for an insignificant download and processing efficiency.
