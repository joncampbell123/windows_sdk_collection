Multi-Step Procedure Topic Template

Microsoft Corporation

Updated June 10, 1999

To copy the template, select the text from the <!DOCTYPE> tag to the </HTML> end tag, right-click, and then click Copy:


<!DOCTYPE HTML PUBLIC "-//IETF//DTD HTML//EN">
<html>
<head>
<title>Example procedure topic</title>
</head>

<body>

<h1>Enter heading for multi-step procedure here</h1>

<ol>

<li>Do the first task.

<li>Do the next task, which may have a <a href="example.asp">link</a> in it.

<li>Do the last task.

</li>
</ol>

<h3>Note</h3>

<ul>
<li>Note text goes here.
</li>
</ul>

<table border="0" cellpadding="0" cellspacing="0"> <tr>
<td valign="top">
<a href="example.asp">Link to another procedure</a>
</td>
</tr>
</table>

</body>
</html>
