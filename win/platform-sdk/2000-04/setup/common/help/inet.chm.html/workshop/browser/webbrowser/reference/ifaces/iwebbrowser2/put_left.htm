IWebBrowser2::put_Left Method

Sets the horizontal position of the Microsoft® Internet Explorer main window.

Syntax

HRESULT put_Left(
    long Left
);

Parameters

Left
Screen coordinate of the left edge of the main window.

Return Value

Returns S_OK to indicate that the operation was successful.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
