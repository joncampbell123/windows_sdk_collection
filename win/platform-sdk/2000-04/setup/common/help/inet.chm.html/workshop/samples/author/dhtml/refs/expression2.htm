The background-color and color of the BODY are using the expression attribute in a linked style sheet to set hex color values based on random decimal values.

The expression calls the fnRandColor function. This function invokes the fnReturnHex function on the fnRandomDec function. In short, a random decimal is created between 0 and 255. This decimal is converted to a hex value. The random color is the result of doing this three times and concatenating the values. You can test this by clicking the "Test Random HEX" button.
