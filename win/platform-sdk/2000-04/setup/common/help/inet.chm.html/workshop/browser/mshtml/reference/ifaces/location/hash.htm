IHTMLLocation::get_hash Method

Retrieves the string following the # symbol in the current URL.

Syntax

HRESULT get_hash(
    BSTR *p 
);

Parameters

p
Address of a variable that receives the hash portion of the current URL. If the URL has no hash string, this parameter receives an empty string.

Return Value

Returns S_OK if successful, or an error code otherwise.

Remarks

This property is useful for moving to a bookmark within a document. Assigning an invalid value does not cause an error.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
