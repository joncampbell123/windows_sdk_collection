IChannelMgr Interface

The IChannelMgr interface provides the ability to add and delete Active Channels and channel categories in the desktop channel bar.

IChannelMgr Methods

AddCategory Adds a channel category to the desktop channel bar.
AddChannelShortcut Installs an Active Channel into the desktop channel bar.
DeleteCategory Deletes a channel category from the desktop channel bar.
DeleteChannelShortcut Deletes an existing Active Channel.
EnumChannels Creates a channel enumerator.

Interface Information

Implementation ChannelMgr Object
Inherits from IUnknown
Header and IDL files Chanmgr.h Chanmgr.idl
Minimum availability Internet Explorer 4.0
Minimum operating systems Windows 95, Windows NT 4.0
