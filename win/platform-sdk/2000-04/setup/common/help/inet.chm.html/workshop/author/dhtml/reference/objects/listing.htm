LISTING Element | LISTING Object

Renders text in a fixed-width font.

HTML Syntax

<LISTING
    CLASS=classname
    ID=string
    LANG=language
    LANGUAGE=JAVASCRIPT | JSCRIPT | VBSCRIPT  | VBS 
    STYLE=css1-properties
    TITLE=text
    event = script
>

Remarks

This tag is no longer recommended. Use the PRE or SAMP tag instead.
