Contact Us


This section includes information to enable you to contact Microsoft Technical Support. If you don't find what you are looking for in this section, please see the technical assistance overview for other resources that may help you.

If you have feedback about the MSDN Online Web Workshop, follow the instructions at write to us.

If you have specific comments about the information on these Technical Assistance pages, please send us your feedback. We're interested in ideas for Frequently Asked Questions (FAQs), Knowledge Base (KB) articles, links, and anything else that would help when you've got a tricky technical problem.

Finally, if you have a technical problem with Networking, Protocols & Data Formats and you're at your wit's end -- you've read through all the documentation, posted to public newsgroups, reviewed the FAQs and Knowledge Base articles, and you still need help -- you can find information on how to contact Developer Support on the Microsoft Support Online Web site. (If you haven't visited the Support Online Web site before, you may be asked to fill out a simple registration form before entering.)

Note: When contacting Microsoft Technical Support, please mention these keywords for faster service: Internet Client Development and URL Monikers or Pluggable Protocols
