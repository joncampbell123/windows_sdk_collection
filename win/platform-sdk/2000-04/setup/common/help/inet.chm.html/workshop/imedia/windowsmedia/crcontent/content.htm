Information for Windows Media Technologies Content Creators

Updated: December 22, 1998

People who create (Advanced Streaming Format) ASF Content need information about how to take an audio or video source and turn it into streaming multimedia. Here are some resources to help content creators get started:

Codecs -- The rundown on why codecs are so important in determining the quality and performance of your ASF content.

Windows Media tools -- Describes the Windows Media tools included in the Windows Media Services download and provided by other companies.

Using the Windows Media Encoder to Create ASFs from AVIs

Microsoft PowerPoint Publish to ASF pages -- The place to get the latest code and information regarding how to use the Publish to ASF feature of Microsoft PowerPoint®.

Third-party tools -- Lists third-party tools that are available to help make creating content served by Windows Media Technologies easier.

Tools tips & tricks -- Click here to get access to a CD designed to help you jump right in and start creating content using Windows Media Technologies.

Windows Media Technologies technical papers -- Downloadable overviews and white papers, including a Windows Media planning and deployment guide.
