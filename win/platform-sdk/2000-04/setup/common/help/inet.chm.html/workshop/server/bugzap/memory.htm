Active Server Pages Memory Leak in Internet Information Server 3.0

Microsoft Corporation

October 10, 1997

If you are running Active Server Pages version 1.0b on Internet Information Server (IIS) version 3.0, you may experience performance problems. These performance problems are caused by a memory leak in ASP.dll, which you can confirm using the Performance Monitor. It is important to note that the hotfix supplied below is only for Microsoft Active Server Pages version 1.0b, and should not be applied to Active Server Pages versions 1.0 or 1.0a.

The hotfix is available at the following location:

ftp://ftp.microsoft.com/bussys/winnt/winnt-public/fixes/usa/nt40/hotfixes-postSP3/as p-fix/

Please be sure to review the Readme notes before applying the fix.

How to Confirm the ASP.dll Version:

  1. Open the Windows Explorer.
  2. Open the WinNT folder.
  3. Open the System32 folder.
  4. Open the Inetsrv folder.
  5. Open the ASP folder. ASP.dll will be in this folder.
  6. Right-click the ASP.dll icon and choose Properties, then select the Version tab to display version information.
  7. Build number 01.18.24 and above corresponds to Active Server Pages Version 1.0b.
