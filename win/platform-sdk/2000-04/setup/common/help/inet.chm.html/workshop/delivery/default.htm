Content & Component Delivery

For navigation tips, please see Using this Site.

This section contains all the information you will need to deliver content and components to your users. The technologies covered include Active Desktop™, software update channels, Open Software Description (OSD), and the Channel Definition Format (CDF).

Active Channel Technology

Using Active Channel Technology you can deliver updated Web content to your users directly, rather than your users having to go get it for themselves. Find out more in our Active Channel Technology tutorials. You can also delivery content to your users' desktops with Active Desktop items.

Component Delivery

This section also includes information on the Internet component download, hit logging, and information delivery APIs. And once you start incorporating these different types of content and component delivery, technical assistance information is available if you need it.
