Enable Users to Customize Information

Microsoft Corporation

June 23, 1998

Information types enable you to tag information in the table of contents so users can customize which topics they see listed. Categories are a way of grouping information types into logical subsets. For example, you could define a category named User Level that includes the following information types: Beginning User and Advanced User. You can use information types either with or without categories.

Once you have created categories and information types, you can select attributes for them and assign help topics to them. Information types have either an Inclusive or Exclusive attribute. A category that contains Inclusive information types allows the user to pick any number of information types in the category.

So, in the example of the User Level category, if you assign an Inclusive attribute to the information types, a user could view both Beginning and Advanced topics. If you assign an Exclusive attribute to the information types, the user could only view one type of information from the User Level category.

If information types have been specified, users can customize which topics they see by right-clicking anywhere on the Contents tab of the default help window, and then clicking Customize on the shortcut menu. Another way to provide information type selection to users is by adding an Options button to any secondary windows you create. The user can click the Options button, and then click Customize.

Information types are a powerful way to enable users to tailor information to their needs.
