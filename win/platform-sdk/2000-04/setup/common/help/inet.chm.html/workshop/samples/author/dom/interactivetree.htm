Interactive Document Tree Sample

This sample demonstrates how the DOM implementation in Internet Explorer can be used to manipulate portions of the document tree. Click one of the nodes in the sample tree to query the different properties displayed in the gray table. Right-click one of the nodes for a special context menu that allows you to copy, paste, create, and remove a selected node. These features are valid only within the sample tree, which is available between the two horizontal rules.
