To Save Compiler Messages to a File

Microsoft Corporation

Updated June 10, 1999

  1. Open a project (.hhp) file, click Change Project Options, and then click the Files tab.

    Change Project Options

    Specifies files, compiler, window, and other project settings.

  2. In the Log file box, type the name of the file. If you want to save the file in a folder other than the one that contains the project file, type a path.

Note

  • You can save all the compiler messages, or hide the ones you don't want to appear in your report.
