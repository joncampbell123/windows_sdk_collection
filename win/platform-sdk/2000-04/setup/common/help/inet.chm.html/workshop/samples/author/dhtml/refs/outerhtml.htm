outerHTML Property Sample

The following sample demonstrates the use of the outerHTML property to copy a Dynamic HTML object to a list when it is clicked. The outerHTML property allows an author to obtain a reference to the object and all accompanying attributes and children. For example, click one of the following items in the list and the outerHTML of the object is appended to the list.

  • Bold text
  • Italic text
  • Underlined text
  • Strikeout text
