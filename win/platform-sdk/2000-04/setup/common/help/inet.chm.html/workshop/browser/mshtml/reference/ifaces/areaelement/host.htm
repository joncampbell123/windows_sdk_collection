IHTMLAreaElement::get_host Method

Retrieves the host name and the optional port information of the location or URL.

Syntax

HRESULT get_host(
    BSTR *p
);

Parameters

p
Address of the string (BSTR) variable where the host name and optional port information will be stored. For details, see the host property.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLAreaElement::put_host Method

Sets the host name and the optional port information of the location or URL.

Syntax

HRESULT put_host(
    BSTR v
);

Parameters

v
String (BSTR) value that specifies the host name and port information to set. For details, see the host property.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
