ABSTRACT Element

Summarizes the associated parent element.

Syntax

<ABSTRACT
    XML-SPACE = "DEFAULT" | "PRESERVE"
>

Attributes

XML-SPACE
String value that specifies how white space—such as a tab, space, or blank line—is treated.
"DEFAULT" Value that permits white space to be filtered out during file processing.
"PRESERVE" Value that ensures all white space characters are retained.

Element Information

Number of occurrences None or one
Parent elements CHANNEL,  IMPLEMENTATION, ITEM,  SOFTPKG
Child elements None
File formats supported CDF, OSD
Requires closing tag Yes

Remarks

When the cursor is paused over a CHANNEL or an ITEM title, Microsoft® Internet Explorer displays the text in the ABSTRACT element in a ToolTip located in the browser channel pane.

ABSTRACT is no longer an attribute of CHANNEL; it is now a separate element.

Example

This example provides a synopsis of an article about creating a CDF file. 

<ABSTRACT>This article describes how to create a CDF file.</ABSTRACT>
