Server Technologies

For navigation tips, please see Using this Site.

In this section you will find a wide range of information about Web server technologies.

Internet Information Services

Internet Information Services (IIS), Windows 2000 Server's set of Web services, is covered in-depth in the Library's SDK and these technical papers. Information on IIS 4.0 and its tuning, security and authentication, performance tips, custom error messages, and debugging is also included.

Active Server Pages (ASP)

To scratch the surface of how ASP can revolutionize how your site functions, read the Introduction and 15 Top Tips. See the Programming Conventions, COM Objects in ASP, and Maximizing ASP Performance for in-depth strategies on improving your ASP code. ASP from A to Z and the Q & A will point you to further resources.

Active Server Components

If you're looking for ready-made Active Server components, see our Catalog. If you're developing components, see COM Threading Models and Threading Models & Performance. There are also several articles on developing Active Server components with technologies such as ASP, Visual Studio 97, ATL, Visual Basic, Java COM objects, and data access.

Site Server

If you're developing intranets, you'll want to take advantage of Site Server's many features. Start with this overview before diving into Creating a Search Catalog, Hosting Multiple User Communities, Knowledge Manager, and the Membership Directory Configuration and Tuning.

Commerce

For $tarters is a great introduction to Commerce topics. Planning Your Commerce Site gets into the nitty-gritty. You may also want to check out the CIP Manager Tutorial and the CIP Manager & SDK. The Duwamish Bookstore site is a completely documented sample commerce site built by our own writers. For comprehensive detail, stop by the online version of the Microsoft Complete Commerce Toolkit .

Site Administration and Development

The Basics of Security provides a great introduction to a topic that is undoubtedly of keen interest to developers and their clients. You'll also find information on Managing Session State in a Web Farm, and Simulating Cookies with the Cookie Munger.

Tools and Utilities

Check out the Web Capacity Analysis tool, IIS Exception Monitor and INetMonitor. We hope to add more tools and utilities soon.

Case Studies and Labs

Also included are several case studies and articles that provide an in-depth look at the settings and performance of sites like Microsoft's own Web site, and a Migration Lab that provides step-by-step help on migrating your server(s).
