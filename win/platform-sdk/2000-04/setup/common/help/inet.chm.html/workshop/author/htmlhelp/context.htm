Create Pop-Up Windows

Microsoft Corporation

June 23, 1998

You can use HTML Help to create pop-up windows for your help system or Web site. Pop-up windows give you the ability to provide an instant definition of a word, phrase, or graphic. Pop-up windows have the following properties:

  • A pop-up window is positioned relative to the mouse. A program can override this with a specific position.
  • By default, the width and height of a pop-up window are determined by the amount of text in the window. You can also set these values.
  • If there is insufficient room on the screen to display the text, the text is clipped. There are no scroll bars in a pop-up window.
  • The pop-up window closes if you click anywhere on the screen or press ESC. If you click a hyperlink, the pop-up window closes and the link is followed.
  • HTML Help pop-up windows are text-only and cannot contain formatted text, links to other topics, or links to images.
