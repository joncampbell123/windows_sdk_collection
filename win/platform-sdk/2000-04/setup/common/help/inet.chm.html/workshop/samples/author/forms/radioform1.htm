INPUT_radio Sample

This sample demonstrates the use of the INPUT_radio control to provide a user with a series of choices. In this sample, a mock multiple-choice question is presented. Notice that by setting the NAME attributes the same, the controls act as a collection. As a collection, only one INPUT_radio control can be checked at a time.
