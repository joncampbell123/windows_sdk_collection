VBScript Memory Leaks

Microsoft Corporation

February 2, 1998

Those of you programming with VBScript for Microsoft® Internet Information Server (IIS) will be glad to know that the Scripting team has just published a hotfix for the following memory leaks:

  • Internet Information Server 3.0: the FormatNumber function
  • Internet Information Server 4.0: the Month(date) function

Applications using either of these VBScript string-formatting functions may experience memory leaks, which will slow performance of the server. The increased resource usage caused by these leaks is particularly detrimental in ASP-enabled (Active Server Pages) environments.

The hotfix applies to any version of the VBScript.dll with version number 3.1.0.2124 and earlier.

The hotfix, incorporated into the Microsoft Scripting Engines Version 3.1, is available on the Scripting Engines download page .

Please be sure to read all the prerequisites before upgrading.
