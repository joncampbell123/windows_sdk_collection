Dynamic HTML Editing Component SDK

Updated February 19, 1999

The DHTML Editing Component is now a part of the minimum Internet Explorer 5 installation. If you have installed Internet Explorer 5, the DHTML Editing Component is already available, and you do not need to download or install it. To get started using the Internet Explorer 5 version of the component, see the DHTML Editing Component page. For information about getting header and include files that you will need to work with the DHTML Editing Component, see "Include and Header Files" in the Requirements section of the DHTML Editing Component documentation.

The SDK that you can download from this page is an earlier version of the DHTML Editing Component (version 1.0) that you can use with Internet Explorer 4.01. This earlier version supports almost all the functionality of the version in Internet Explorer 5, and you can upgrade from the earlier to the current version without code changes at a later time. A list of the differences between the 1.0 version and the version shipped with Internet Explorer 5.0 is listed in the topic called What's New for the DHTML Editing Component in Internet Explorer 5.

You will want to download the SDK and use the 1.0 version of the DHTML Editing Component if:
  • Your users are not yet using Internet Explorer 5.
  • You are creating a Web-based application for a broad audience (such as a public Web site).

Click below to download dhedsdk.exe, and then run the file. The program will lead you through the SDK installation process and prompt you for an installation directory.
