SCRIPTINFO Structure

Contains the information about the specified script.

Syntax

typedef struct tagSCRIPINFO{
    SCRIPT_ID   ScriptId;
    UINT        uiCodePage;                         
    WCHAR       wszDescription[MAX_SCRIPT_NAME];
    WCHAR       wszFixedWidthFont[MAX_MIMEFACE_NAME];
    WCHAR       wszProportionalFont[MAX_MIMEFACE_NAME];
} SCRIPTINFO, *PSCRIPTINFO;

Members

ScriptId
SCRIPT_ID that is associated with the script.
uiCodePage
Unsigned integer value that contains the code page associated with the script.
wszDescription
Array of wide characters that contains the description of the script.
wszFixedWidthFont
Array of wide characters that contains the name of the fixed-width font associated with the script.
wszProportionalFont
Array of wide characters that contains the name of the proportional font associated with the script.

Structure Information
