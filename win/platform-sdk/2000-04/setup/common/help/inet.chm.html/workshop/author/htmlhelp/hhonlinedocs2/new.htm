New Features in This Release

Microsoft Corporation

Updated June 10, 1999

Along with feature upgrades, the Microsoft HTML Help 1.2 release contains these new features:

  • Adding a Favorites tab to the Navigation pane in a compiled help (.chm) file.
  • Adding advanced full-text search features to the Search tab in a compiled help file.
  • Adding a full-text search stop list to your compiled help file.
  • Automatic hiding of the Navigation pane when a user switches focus from a compiled help file to a software program.
  • New accessibility shortcut keys and documentation explaining how to use them added to the HTML Help Viewer.
  • Updated and expanded documentation.
