XML DOM Reference

Welcome to the XML Document Object Model (DOM) Reference documentation.

The DOM is a World Wide Web Consortium (W3C) recommendation available at http://www.w3.org/TR/REC-DOM-Level-1/  (October 1, 1998).

This reference documentation supplements the W3C recommendation and offers details relating to the Microsoft implementation supplied with Microsoft® Internet Explorer 5.

This documentation is provided in different formats for two different audiences:

  • XML DOM Interfaces (COM programming interfaces, for C/C++ and Microsoft® Visual Basic® developers)
  • XML DOM Objects (ActiveX® programming objects, for developers using script languages)
