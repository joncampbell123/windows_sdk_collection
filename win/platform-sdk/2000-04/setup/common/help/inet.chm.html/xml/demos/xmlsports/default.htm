XML Sports Demo

March 18, 1999

version 1.0

Software Requirements

The demo should be installed on a machine with the following software installed and configured:

  • Windows NT Server 4.0 with Internet Information Server
  • Windows NT Service Pack 3
  • Windows NT Option Pack 4 (Internet Information Server 4, SMTP Server)
  • Internet Explorer 5

Installation

Download the XML Sports Demo (approx 1.9Mb).

The XML Sports Demo installer will prompt you for a directory for installation. The setup program assumes that "C:\InetPub\wwwroot" is your root web directory. If it is not, install the demo in a directory named "xmlsports" in your root web directory. You must install the demo in the root directory of the web server.

Using the Mail Service

The mail feature on the XMLstatzone site depends on SMTP Service. Make sure SMTP service is installed and configured properly. When entering profile information on the My Stats page, the user should enter name@server where name is the desired email name and server is the name of the machine (e.g. john@johnmach). The mail service will then deliver the messages to the drop folder in the Mailroot directory and allow them to be read by the Check Mail page.

Using the Sports Agent

The Sports Agent feature requires the Microsoft Agent core components, the Merlin character, and a text-to-speech engine to be installed. These components can be installed from the Microsoft Agent Downloads for Developers page.

Troubleshooting

If you experience problems loading the demo in the browser, try stopping and re-starting the web services.

If re-starting IIS does not solve the problem, check to make sure a web application has been created. Open your IIS Administration console, and check if the directory that you chose to install the demo in is an application. Right click on the name of the directory, and select 'Properties', and select the 'Directory' tab. If the directory is not an application, you will be given the option to 'Create' an application. Click the 'Create' button, and close the dialog box. Open the properties of the "xmlstatzone" directory and give it directory 'Write' permissions.

If you are unable to update the database in XMLStatZone or XMLFantasyFootball, you will need to open Windows Explorer and view the properties of the "xmlsports\database" direcory. Select the 'Security' tab, and click the 'Permissions' button. Make sure that the "Replace Permsissions on Existing Files" option is checked, and then set the type of access for "Everyone" to "Full Control".
