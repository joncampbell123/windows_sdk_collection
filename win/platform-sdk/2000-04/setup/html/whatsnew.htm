These Windows products provide a wealth of new technologies that allow your application to reach new heights. Below are highlights of some of the new and updated technologies.

Asynchronous Remote Procedure Calls (RPC)

Asynchronous RPC allows your programs to handle multiple outstanding calls from a single-threaded client and prevent data transmission bottlenecks that can arise from slow or delayed clients or servers. With asynchronous pipe parameters, client/server applications can transfer large amounts of data incrementally, without blocking the client or server threads from performing other tasks.

For more information, see the Asynchronous RPC section in the Platform SDK documentation.

Base Services

The following topics have been added under the Base Services node: battery information, disk quotas, dynamic-link library redirection, job objects, opportunistic locks, reparse points, sparse files, thread pooling, timer queues.

For more information, see the Base Services section in the Platform SDK documentation.

CDO

CDO for Windows 2000 is an OLE Automation-compatible COM component that you can use to add Internet-standard messaging functionality in your Windows 2000 applications. CDO supports construction and manipulation of messages formatted according to Internet standard formats such as those defined by the RFC 822 and Multipurpose Internet Mail Extensions (MIME) specifications. You can transmit messages using both the Simple Mail Transfer (SMTP) and Network News Transfer (NNTP) protocols, or local SMTP/NNTP service pickup directories.

CDO for Windows 2000 can also be used to implement SMTP/NNTP transport event sinks on Windows 2000. Such sinks can intercept messages as they arrive to the particular service, and the sink can possibly examine or modify the message, or block its further transmission altogether. CDO for Windows 2000 is not based in any way upon the Messaging API (MAPI).

For more information, see the Messaging and Collaboration Services section in the Platform SDK documentation.

Certificate Services

Certificate Services provides customizable services for issuing and managing certificates used in software security systems employing public-key cryptography. Certificate Services performs a central role in the management of software security systems to enable secure communications across the Internet, corporate Intranets, and other networks that are not secured.

For more information, see the Security section in the Platform SDK documentation.

Common Controls

The following topics have been added under Windows Common Controls: ComboBoxEx controls, Custom draw, Date and time picker controls, Flat scroll bars, IP address controls, Month calendar controls, Pager controls, and Rebar controls.

For more information, see the Windows Common Controls section in the Platform SDK documentation.

Custom Scripting for Remote Access Connections

Remote Access Service (RAS) now supports custom-scripting DLLs. Custom-scripting DLLs run on the RAS client. A custom-scripting DLL can send and receive data over the port for the RAS connection. RAS provides the DLL with the phone-book entry that RAS dialed for the connection. As a result, the DLL can take "special-case" actions for particular phone-book entries.

For more information, see the RasCustomScriptExecute section in the Platform SDK documentation.

Device Management (Plug and Play)

Applications and services can register to receive selected device change events.

For more information, see the RegisterDeviceNotification UnregisterDeviceNotification section in the Platform SDK documentation.

Distributed Link Tracking

Distributed link tracking enables client applications to track link sources that have been moved. As a result, clients that subscribe to the link-tracking service can maintain the integrity of their references, and the objects referenced can be moved transparently. The link-tracking service in Windows 2000 tracks link sources for shell shortcuts and OLE links within NTFS version 5.0 volumes.

For more information, see the Distributed Link Tracking section in the Platform SDK documentation.

Domain Name System (DNS)

DNS is an industry-standard protocol used to locate computers on an IP-based network. It is the locator service of choice in Windows 2000.

For more information, see the Network Management section in the Platform SDK documentation.

Dynamic Host Configuration Protocol (DHCP)

The DHCP Application Programming Interface, also referred to as DHCP Client Options, enables Windows 2000 and Windows 98 clients to query specific options from DHCP Servers. Such capability enables vendor-specific options exposed through DHCP servers to be queried by Windows 2000 or Windows 98 DHCP clients.

For more information, see the Network Management section in the Platform SDK documentation.

Encrypted File System (EFS)

The encrypted file system supports encrypting and decrypting files or directories on NTFS volumes.

For more information, see the File Encryption section in the Platform SDK documentation.

Event Tracing

The Event Tracing API is designed for tracing and logging very high-frequency events with minimal impact on system resources. This is useful for measuring demands on system resources.

For more information, see the Event Tracing section in the Platform SDK documentation.

Extensible Authentication Protocol (EAP)

You can now use Extensible Authentication Protocols (EAPs) to authenticate multilink and callback connections. The PPP_EAP_INPUT structure and the RasEapGetIdentity functions have been modified to support the new functionality.

For more information, see the Multilink and Callback Connections section in the Platform SDK documentation.

Fax service

Fax service provides programming interfaces for developing fax client applications and extending the Fax Service.

For more information, see the Networking and Directory Services section in the Platform SDK documentation.

Group Policy

Group Policy uses the file system, directory services, and security group membership to support per-user and per-machine configuration settings.

For more information, see the Management Services section in the Platform SDK documentation.

Indexing Service 3.0

Indexing Service 3.0 indexes the contents of all drives on the computer where it is installed, allowing the user to search for any word or phrase on those drives.

For more information, see the Indexing Service section in the Platform SDK documentation.

Internet Authentication Service (IAS)

IAS allows developers to implement session control and accounting plug-ins, add authorizations, or use network authentication methods for remote access. IAS supports, as a client and server, the Remote Authentication Dial-In User Service (RADIUS) protocol.

For more information, see the Network Security section in the Platform SDK documentation.

Internet Information Services

IIS interfaces and methods enable you to create components for access by ISAPI, ASP components, and advanced ASP scripting techniques. The documentation also contains information on the metabase; a fast-access, memory-resident data store used by IIS. A library of script and program samples demonstrates ways that you can use built-in objects to manipulate data, log server activity, replicate configuration information, and extend the environment to automate tasks.

For more information, see the Web Services section in the Platform SDK documentation.

Jet and Replication Objects (JRO)

JRO allows you to add features to your application that are specific to the Microsoft Jet Database Engine.

For more information, see the Data Access Services section in the Platform SDK documentation.

LSA Authentication

LSA Authentication describes those parts of the Local Security Authority (LSA) that applications can use to authenticate and log users on to the local system.

For more information, see the Security Logon Authentication section in the Platform SDK documentation.

Microsoft Agent

Microsoft Agent is a set of programmable software services that supports interactive animated characters within the Microsoft Windows interface. You can use characters as interactive assistants to introduce, guide, entertain, or otherwise enhance Web pages or applications. Microsoft Agent enables you to add conversational interfaces, which leverage natural aspects of human social communication. Microsoft Agent also includes optional support for speech recognition so applications can respond to voice commands. Characters can respond using synthesized speech, recorded audio, or text in a cartoon word balloon.

For more information, see the User Interface Services section in the Platform SDK documentation.

Microsoft DirectX

Microsoft DirectX® 7.0 provides ease-of-use enhancements, expanded capabilities, and improved performance to Microsoft DirectDraw® and Microsoft Direct3D® Immediate Mode components of DirectX. The documentation throughout DirectX has been expanded to include new overviews and tutorials.

For more information, see the What's New in DirectX Foundation section in the Platform SDK documentation.

Microsoft Management Console (MMC)

The Microsoft Management Console is an extensible user interface that provides an environment for running systems management applications, which are structured as components called snap-ins.

For more information, see the Management Services section in the Platform SDK documentation.

Multicast Address Dynamic Client Allocation Protocol (MADCAP)

Multicast Address Dynamic Client Allocation Protocol (MADCAP) enables clients to query and request multicast addresses from multicast (MADCAP) servers. By using this set of client APIs, MADCAP clients can lease, renew, and release multicast addresses from qualifying MADCAP servers across the network.

For more information, see the Network Management section in the Platform SDK documentation.

Multicast Group Manager

The Multicast Group Manager (MGM) API makes it possible to access the multicast routing capabilities of Microsoft Windows 2000 Server. Using MGM, you can write routing protocols that interact with MGM to receive and forward multicast data using both calls to MGM and callbacks from MGM. You can also write administrative applications that track group membership.

For more information, see the Routing and Remote Access Services section in the Platform SDK documentation.

Multiple display monitors

A single interactive window station can support multiple display monitors.

For more information, see the Windows GDI section in the Platform SDK documentation.

Network Load Balancing Provider

Network Load Balancing clusters balance TCP/IP connection loads across multiple ports and servers according to a configurable set of rules. The Network Load Balancing Provider allows developers to create customized, remote, scriptable administration tools for Network Load Balancing clusters.

For more information, see the Windows Clustering section in the Platform SDK documentation.

Network Monitor

All new information on programming for Network Monitor 2.0. Information ranges from analyzing previously captured data in user-defined methods, to extracting data from defined protocol parsers, to real-time analysis of traffic on your network.

For more information, see the Networking and Directory Services section in the Platform SDK documentation.

Network Provider API

The Network Provider API provides an interface between the Multiple Provider Router and network providers, including credential manager providers.

For more information, see the Security Logon Authentication section in the Platform SDK documentation.

Password Filters

Password filters provide a way for you to implement password policy and change notification for passwords.

For more information, see the Security Logon Authentication section in the Platform SDK documentation.

Power management

To save power and ensure that no data is lost when a computer or device is turned off or placed in a low power state, Windows provides power management support. Windows 2000 supports OnNow Power Management.

For more information, see the Power Management section in the Platform SDK documentation.

Quality of Service (QOS)

Quality of Service is fully functional in its implementation within Windows 2000. QOS also is available in Windows 98. However, Windows 98 does not implement all of the features found in Windows 2000.

For more information, see the Windows 98 QOS Notes section in the Platform SDK documentation.

Removable Storage Manager

Removable Storage Manager facilitates communication among applications, robotic changers, and media libraries. It enables multiple applications to share local robotic media libraries and tape or disk drives, and manage removable media within a single-server system.

For more information, see the Removable Storage Manager section in the Platform SDK documentation.

Routing Table Manager Version 2

Routing Table Manager Version 2 (RTMv2) is a new version of the Routing Table Manager Version 1 (RTMv1) API. RTMv2 makes it possible to use the routing table manager for Microsoft Windows 2000 Server, and to develop routing protocols for the Internet Protocol (IP) transport. Routing protocols can modify and query the routing table, and they can use protocol-specific information to determine interoperability actions. RTMv2 can also be used to develop methods that are exported for other routing protocols to invoke.

For more information, see the Routing and Remote Access Services section in the Platform SDK documentation.

RPC name service

The RPC Name Service (Locator) uses the Active Directory as its database. This means that exported entries can be made persistent even when a server is rebooted.

For more information, see the RpcNsBindingExport, RpcNsBindingImportNext, RpcNsBindingLookupBegin, RpcNsBindingUnexport sections in the Platform SDK documentation.

Smart Card Enrollment Control

Smart Card Enrollment Control enables Windows 2000 administrators to obtain certificates for smart card users.

For more information, see the Smart Card Enrollement Control section in the Platform SDK documentation.

TAPI 3.0

Telephony Application Programming Interface (TAPI) 3.0 is based on the Component Object Model (COM) and uses Microsoft DirectShow® filters to provide access to the media.

For more information, see the Telephony Application Programming Interfaces section in the Platform SDK documentation.

Task Scheduler

The Task Scheduler lets you perform automated tasks on a chosen computer. The Task Scheduler monitors whatever criteria you set and executes the task when the criteria for executing the task have been met.

For more information, see the Management Services section in the Platform SDK documentation.

Web Telephony Engine

The Microsoft Web telephony engine is a Windows 2000 run-time service that renders web-based interactive voice response (IVR) applications. This service lets you use familiar web development tools such as HTML, Microsoft ActiveX controls, scripting, and Active Server Pages (ASP) to create dual-access telephony applications accessible by both telephone and Internet browser.

For more information, see the Web Telephony Engine section in the Platform SDK documentation.

Windows File Protection

Windows File Protection (WFP) prevents the replacement of essential system files installed as part of Windows 2000. Protecting these files prevents application and operating system failures.

For more information, see the Management Services section in the Platform SDK documentation.

Windows GDI

The following topics have been added under Windows GDI: Alpha blending, Smooth shading, Setting and retrieving the color of the pen or brush, and Window layouts.

For more information, see the Windows GDI section in the Platform SDK documentation.

Windows Installer

Windows Installer supports installation-on-demand. As the user works, the required features and components are installed on the local hard drive only when needed.

For more information, see the Setup section in the Platform SDK documentation.

Windows NetMeeting 3

Windows NetMeeting 3 provides a software application programming interface (API) that lets programmers and Web-page designers include collaboration and conferencing for applications that are NetMeeting clients. Data conferencing includes application-sharing, chat, whiteboard, and file transfer features. Other features include remote-desktop sharing and gatekeeper support.

For more information, see the Messaging and Collaboration Services section in the Platform SDK documentation.

Windows User Interface

The following have been added under Windows User Interface: Special effects when showing or hiding windows.
The new Print Property Sheet common dialog box interface displays the Print property sheet available in Windows 2000.
Windows 2000 and Windows 98 have new restrictions on which applications can set the foreground window. For more information, see AllowSetForegroundWindow and LockSetForegroundWindow.
Layered windows enable you to create improved visual effects.
Improvements to support for flashing windows (see FlashWindowEx).
Retrieving the history of mouse and pen coordinates (see GetMouseMovePointsEx).

For more information, see the User Interface Services section in the Platform SDK documentation.

Winlogon and GINA

Winlogon provides interactive logon support. It is designed around an interactive logon model that consists of three components: the Winlogon executable, a Graphical Identification and Authentication dynamic-link library (referred to as the GINA ), and any number of network providers.

For more information, see the Security Logon Authentication section in the Platform SDK documentation.

Windows Management Instrumentation (WMI)

Windows Management Instrumentation (WMI) is the Microsoft implementation of Web-Based Enterprise Management (WBEM), which is an industry initiative to develop a standard technology for accessing management information in an enterprise environment. This release of WMI includes many optimizations and improvements.

For more information, see the Management Services section in the Platform SDK documentation.
