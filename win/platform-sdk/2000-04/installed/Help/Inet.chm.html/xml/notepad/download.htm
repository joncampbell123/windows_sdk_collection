Downloading XML Notepad

Beta 1.5
May 15, 1999

Before you download Microsoft® XML Notepad, make sure that your system meets the requirements below:

  • Processor: 486/66 or higher.
  • Operating system: Windows® 95, Windows 98, or Windows NT® 4.0 running Microsoft® Internet Explorer version 4.01 or later for Windows 95 and Windows NT 4.0 with Service Pack 1 installed. (We recommend that you install Microsoft Internet Explorer 5 for additional feature support.)
  • Memory: 3.8 MB RAM. This is the memory required for an empty file with Internet Explorer 4, and includes requirements for all DLLs, UI components, etc. Additional memory required for XML data is dependent on the data set. About 0.75 MB is needed for each 64K of XML file size. Running XML Notepad with Internet Explorer 5 requires slightly more memory.
  • Disk space: 1 MB to install, 0.5 MB to run XML Notepad.
  • Download size: 0.6 MB.

Download Instructions

Before you click the download link below, be sure to review the License Agreement for Microsoft XML Notepad provided with this tool.

XML Notepad Beta 1.5 Installer (xpsetup.exe; 335K)

When prompted, choose Run this program from its current location. (If you select Save this file to disk, you can find the xpsetup.exe file where you saved it on your hard drive, and double-click it to start setup.)

The setup program will guide you through the rest of the installation. Follow the instructions on the screen.

Be sure to read the XML Notepad Release Notes included on this site before running XML Notepad for the first time.
