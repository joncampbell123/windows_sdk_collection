Microsoft XML Parser in Java


Updated: August 10, 1999

The Microsoft XML parser in Java is now integrated into the Microsoft Virtual Machine and available from http://www.microsoft.com/java/ .

The Microsoft XML parser in Java shipped with Internet Explorer 4 and remains available with Internet Explorer 5. This parser, however, is deprecated and has not been updated to reflect W3C activities or other more current Microsoft XML technologies. For a Java parser that tracks the functionality of the Microsoft MSXML Parser that shiped with Internet Explorer 5, see the Data Channel Java Parser available at http://www.datachannel.com .

Note that the Microsoft XML parser in Java that shiped with Internet Explorer 5 contains some bug fixes that make it different from the Java parser that shipped with Internet Explorer 4.0:

  • The as attribute is now called prefix.
  • The href attribute is now called src and is optional.
  • A new required attribute for uniquely identifying the namespace was added which is called ns.
  • The parser now sets jdk11 to true for any version number that is converted to floating point and is greater or equal to "1.1".
  • It prevents loading XML that contains non-standard short end tags.

In order to download the source code (90 KB zipped), you must first read and approve the end user license agreement.
