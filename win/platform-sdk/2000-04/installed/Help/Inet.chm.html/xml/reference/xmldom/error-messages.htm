Error Messages

Msxml.dll errors are generated by either the parser, the Document Object Model(DOM), the XSL or XQL processors, or the MIME viewer.

The following topics each provide a list of error messages returned by the MSXML.DLL:

  • IXMLParseError Error Messages
  • XML DOM Error Messages
  • XSL Error Messages
  • XQL Error Messages
  • MIMETYPE Viewer Error Messages
