XML DOM Persistence

For scripting purposes, persistence is handled with the following methods and property:

  • load
  • loadXML
  • save
  • xml

For VB and C/C++ programmers, DOM persistence is handled with the following methods, property, and interfaces:

  • IXMLDOMDocument::Load Method
  • IXMLDOMDocument::LoadXML Method
  • IXMLDOMDocument::Save Method
  • IXMLDOMNode::XML Property
  • IPersistStreamInit
  • IPersistMoniker
  • IStream
