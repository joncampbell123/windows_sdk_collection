IHTMLScriptElement::get_type Method

Retrieves the string that represents the language in which the current script was written.

Syntax

HRESULT get_type(
    BSTR *p 
);

Parameters

p
Address of a string (BSTR) that specifies the type of language. The language can be Microsoft® JScript® (compatible with ECMA 262 language specification) or Microsoft® Visual Basic® (VBScript).

Return Value

Returns S_OK if successful, or an error code otherwise.

Remarks

This is an HTML attribute and is equivalent to the language property.

The default language is JScript (compatible with ECMA 262 language specification).

This method specifies the type script of the scripting language as a string for the IHTMLScriptElement object. The contents of this script are read-only and can be modified only at design time.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
