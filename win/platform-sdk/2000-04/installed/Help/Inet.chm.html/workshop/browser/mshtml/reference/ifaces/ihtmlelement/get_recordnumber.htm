IHTMLElement::get_recordNumber Method

Retrieves the ordinal record from the data set that generated the element. Applies to a bound, repeated table.

Syntax

HRESULT get_recordNumber(
    VARIANT *p
);

Parameters

p
Address of a VARIANT structure that receives the ordinal record.

Return Value

Returns S_OK if successful, or an error code otherwise.

Remarks

This property can be used in conjunction with the ADO recordset available from every data source object through the recordset property of the object.
