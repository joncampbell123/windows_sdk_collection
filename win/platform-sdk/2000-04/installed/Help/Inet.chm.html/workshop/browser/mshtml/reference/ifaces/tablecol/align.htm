IHTMLTableCol::get_align Method

Displays the element left-aligned, right-aligned, or centered relative to the display or table.

Syntax

HRESULT get_align(
    BSTR *p 
);

Parameters

p
Address of a string variable that receives one of these values:

center Aligns to the center.
left Aligns to the left edge.
right Aligns to the right edge.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLTableCol::put_align Method

Displays the element left-aligned, right-aligned, or centered relative to the display or table.

Syntax

HRESULT put_align(
    BSTR v 
);

Parameters

v
String that specifies the alignment. Can be one of these values:

center Aligns to the center.
left Aligns to the left edge.
right Aligns to the right edge.

Return Value

Returns S_OK if successful, or an error code otherwise.
