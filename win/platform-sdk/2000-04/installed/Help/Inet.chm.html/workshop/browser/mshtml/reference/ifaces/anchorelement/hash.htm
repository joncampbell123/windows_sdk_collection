IHTMLAnchorElement::get_hash Method

Retrieves the string associated with the hash property of the A object.

Syntax

HRESULT get_hash(
    BSTR *p
);

Parameters

p
Address of a string (BSTR) variable that receives the value.

Return Value

Returns S_OK if successful, or an error code otherwise.

Remarks

This property is useful for moving to a bookmark within a document. Assigning an invalid value does not cause an error.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLAnchorElement::put_hash Method

Sets the string following the hash (#) symbol in the HREF attribute of the anchor element.

Syntax

HRESULT put_hash(
    BSTR v
);

Parameters

v
String (BSTR) value that specifies the hash portion of the URL to set.

Return Value

Returns S_OK if successful, or an error code otherwise.

Remarks

This property is useful for moving to a bookmark within a document. Assigning an invalid value does not cause an error.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
