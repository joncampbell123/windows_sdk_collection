IHTMLCurrentStyle::get_lineBreak Method

Retrieves the current value of the lineBreak property of the element.

Syntax

HRESULT get_lineBreak(
    BSTR *p
);

Parameters

p
Address of a string (BSTR) that contains the lineBreak property of the element.

Return Value

Returns S_OK if successful, or an error code otherwise.

IHTMLCurrentStyle::put_lineBreak Method

Sets the current value of the lineBreak property of the element.

Syntax

HRESULT put_lineBreak(
    BSTR v
);

Parameters

v
String (BSTR) that contains the lineBreak property of the element to set.

Return Value

Returns S_OK if successful, or an error code otherwise.
