ondragend Event

Fires on the source object when the mouse is released at the close of a drag operation.

Syntax

void ondragend(
    IHTMLEventObj *pEvtObj
);

Parameters

pEvtObj
[in] Address of an IHTMLEventObj interface variable.

Return Value

None. The event continues processing with the parent element's event handler.

Remarks

For more information, see ondragend in the Dynamic HTML (DHTML) reference page.

This event is available in Microsoft® Internet Explorer 5 and later.

Applies To

Anchor, Area, Button, Document, Element, Form, Image, InputFile, InputImage, InputText, Link, Label, Map, Marquee, Object, OptionButton, Script, Select, Style, Table, TextContainer, Window2
