ITargetFrame2 Interface

This interface provides methods for retrieving and setting frame data.

ITargetFrame2 Methods

FindFrame Searches for a particular frame.
GetFrameMargins Retrieves the margins of the frame.
GetFrameName Retrieves the name of the frame.
GetFrameOptions Retrieves the options that are set for the frame.
GetFramesContainer Retrieves a container object for the frames.
GetFrameSrc Retrieves the URL to load into the frame.
GetParentFrame Retrieve the parent of the frame.
GetTargetAlias Retrieves the alias of the target frame.
SetFrameMargins Sets the margins of the frame.
SetFrameName Sets the name of the frame.
SetFrameOptions Sets the options for the frame.
SetFrameSrc Sets the URL to load into the frame.

Interface Information

Implementation Mshtml.dll
Inherits from IUnknown
Header and IDL files Htiframe.h; Htiframe.idl
Minimum availability Internet Explorer 5
Minimum operating systems Windows 95, Windows NT 4.0
