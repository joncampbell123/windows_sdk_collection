IWebBrowser2::get_Name Method

Retrieves the name of the object that contains the WebBrowser control used by Microsoft® Internet Explorer.

Syntax

HRESULT get_Name(
    BSTR* pbstrName
);

Parameters

pbstrName
Address of a callee-allocated string (BSTR) that receives the name of the object that contains the WebBrowser control. The caller frees this buffer with the SysFreeString function.

Return Value

Returns S_OK if the operation was successful.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
