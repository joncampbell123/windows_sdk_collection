IHTMLRuleStyle::get_font Method

Retrieves the values of the font-style, font-variant, font-weight, font-size, line-height, and font-family attributes for the element.

Syntax

HRESULT get_font(
    BSTR *p 
);

Parameters

p
Address of a variable that receives the values of the font-related cascading style sheets (CSS) attributes. For details, see the font attribute. This parameter receives NULL if no font-related CSS attributes are set for the element.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLRuleStyle::put_font Method

Sets the value of the font-style, font-variant, font-weight, font-size, line-height, and font-family attributes for the element.

Syntax

HRESULT put_font(
    BSTR v 
);

Parameters

v
String that specifies values for one or more font attributes. This parameter has the following format: 
[<font-style> || <font-variant> || <font-weight>] <font-size> /
[<line-height>] <font-family>
For details, see the font attribute.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
