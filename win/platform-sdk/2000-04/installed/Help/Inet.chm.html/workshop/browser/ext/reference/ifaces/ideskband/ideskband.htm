IDeskBand Interface


IDeskBand is used to obtain information about a band object. See the Creating Custom Explorer Bars, Tool Bands, and Desk Bands article for more information about band objects.

When to Implement

Implement IDeskBand if you are implementing a band object.

When to Use

You do not call this interface directly. IDeskBand is used by the shell or the browser to obtain display information for a band object.

IDeskBand Methods

GetBandInfo Retrieves the information for a band object.

Interface Information

Implementation Custom
Inherits from IDockingWindow
Header and IDL files Shlobj.h, Shlobj.idl
Minimum availability Internet Explorer 4.0
Minimum operating systems Windows 95, Windows NT 4.0
