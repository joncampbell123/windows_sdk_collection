IHTMLBodyElement::get_noWrap Method

Retrieves the value that indicates whether automatic wordwrapping is enabled or disabled for the document.

Syntax

HRESULT get_noWrap(
    VARIANT_BOOL *p
);

Parameters

p
Address of a VARIANT Boolean structure that receives VARIANT_TRUE if automatic wordwrapping is enabled for the document, or VARIANT_FALSE otherwise. The default value for this property is VARIANT_FALSE. For details, see the noWrap property.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0

IHTMLBodyElement::put_noWrap Method

Sets the value that indicates whether automatic wordwrapping is enabled or disabled for the document.

Syntax

HRESULT put_noWrap(
    VARIANT_BOOL v
);

Parameters

v
VARIANT Boolean structure that contains the wordwrap flag to set. If VARIANT_TRUE, the browser performs automatic wordwrapping for the document. If VARIANT_FALSE, it doesn't. The default value for this property is VARIANT_FALSE. For details, see the noWrap property.

Return Value

Returns S_OK if successful, or an error code otherwise.

Windows CE

Windows CE Use version 2.12 and later
Minimum availability Internet Explorer 4.0
