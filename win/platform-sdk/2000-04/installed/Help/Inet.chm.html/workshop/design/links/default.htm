Explore helpful Internet design-related links that cover articles, references, graphics samples, and tools.

Articles and references:

Improving Web Site Usability and Appeal

This article provides a helpful, in-depth look at how to enhance your Web site and encourage return visits. It includes content planning, media use, page and site structure, and promotion -- and provides checklists for each section.

Color Vision Color Deficiency

Diane Wilson, a software designer and self-described Generalist at Large, explores issues of color usage and provides examples.

Data Visualization Made Easy -- Part 1: Prepping Your Data

SBN's Robert Carter and George Young team up to show how visual data display can change how your pages look -- and how easily they're read.

Tuning Your Images for the Web 

Seybold Publications  article by Andy Houldsworth  on designing Web graphics, with discussions on GIF, JPEG, and PNG formats -- plus lots of samples.

Cascading Style Sheets in Internet Explorer 4.0

A comprehensive look at CSS and how it can enhance your Web pages in Internet Explorer 4.0.

DHTML, HTML and CSS

This site provides an overview, FAQ, tutorial, and more on how DHTML can add design flexibility and expand your creative choices.

Using Frame Sets with JScript

Explains how the sophisticated set of framesets were implemented on The Nature Conservancy Web site.

Authoring Strategies for Internet Explorer 4.0 and 3.0

A good place to check, and see what has changed.

ActiveX Control Overview

This overview explains, in layman's terms, what an ActiveX™ control is, why you might be interested in using controls, and how you can start writing your own controls. It also includes an FAQ that answers questions we've received from users, and pointers to ActiveX controls you can use today on your Web pages.

Web Pages That Suck

Link to a site that discusses Web design, with examples and running commentary.

Web Page Design -- for Designers

Link to a site that has many articles and tips on Web design, as well as a tutorial and a lively forum. An offline version of the site is also available to download for reference.

Web Men Talking

Do you have scripting and coding questions? Talk to the Web Men. They're happy to answer your technical questions, if they haven't already!

This utility makes it easy to add ActiveX controls and ActiveX scripting (VBScript or JavaScript) to your HTML pages. The ActiveX Control Pad also includes WYSIWYG support for authoring 2-D layout regions in conjunction with the Microsoft HTML Layout Control (below).

Microsoft FrontPage 98

This client/server application helps you create, deploy, maintain, and administer a sophisticated Web site that includes rich Web pages and interactive functions without programming.

DirectX

The Microsoft DirectX APIs are an integrated set of programming tools that cover every aspect of multimedia development. This site provides a fact sheet, backgrounder, and technical backgrounder.

GIF Animator

Microsoft GIF Animator is the fast and easy way to create and customize animation for the Web. Information, sample pages, and download opportunities are available from the Image Composer site.

Image Composer

Information, sample images, and opportunities to download Microsoft Image Composer, a new image composition and editing application that pioneers the use of images with shape.

Windows Media Technology

Windows Media Technology (WMT) is an open software platform for delivering live and on-demand multimedia content over networks. WMT enables multicasting of live audio and data, and storing and streaming of multimedia content.

Microsoft Typography

Information on Web typography and embedding fonts, plus free Windows and Apple Macintosh fonts and utilities you can download to use on your Web pages.
