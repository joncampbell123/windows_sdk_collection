The Design area is the MSDN Online Web Workshop's online resource for creative professionals, which includes information on Web technologies, tools, color management, typography, and Web design. These pages have been built using style sheets, optimized for Internet Explorer 4.0 on a Windows 95 platform.

What design topics would you like us to explore on this site? Your feedback is important to us. Please send mail to msdn@microsoft.com, and be sure to include "Design" in the subject line.

How can you use color effectively on your Web site? Learn about the safe browser palette, using color names, effective color management, and color tables -- plus color information from Pantone.

creative materials
