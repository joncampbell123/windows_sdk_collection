Uses Microsoft Agent Technology Logo Program

Microsoft Corporation

April 14, 1999

By enrolling in the Uses Microsoft Agent Technology Logo Program, you can identify your Web page or application as using the Microsoft Agent technology by displaying the Logo on your Web page or your product's package. This program consists of two parts -- a Microsoft Agent logo for use online, and an Agent logo for use on packaging and marketing materials.

Prerequisites and Criteria for Using the Uses Microsoft Agent Technology Logo

  1. You must accept all the terms and conditions, provide all required information, and execute the Uses Microsoft Agent Technology license agreement.
  2. To use the Microsoft Agent online logo, you must also be in compliance with all the terms and conditions of the End User License Agreement for Microsoft Agent Technology.
  3. To use the Microsoft Agent logo on packaging and marketing material, you must also have a valid License and Distribution Agreement for Microsoft Agent Technology.
  4. Your Web site or application must use the Microsoft Agent API to display a visible character.
  5. Your Web site or product must use the latest version of Microsoft Agent.
  6. You must submit a URL, sample of product, and/or collateral material on which the logo is to appear.

Instructions

Before you proceed, you should have the following information ready:

  1. The URL of your Web page, or the name and version number of your product.
  2. A short description of your Web page or product.
  3. Your name, address, and phone number.
  4. Your company's name, address, and phone number if applicable. Also, make sure you are authorized to represent your company.
