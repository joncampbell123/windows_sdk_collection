Useful Links

Updated January 4, 1999

The Windows Media Services Web site is the place to get information and the latest news about Windows Media Services and the Windows Media Player. Here's a list of useful links for additional information on content creation, usage, and administration.

  • Capture cards -- A list of capture cards that have been tested with Windows Media Services.
  • Windows Media Technologies Showcase -- View cool demos that incorporate advanced features of the Windows Media Technologies. Many demos include code samples.
  • JumpStart CD -- Order the JumpStart CD. Learn about creating content and how to check out third-party tools.
  • Windows Media Services SDK -- Download the SDK for the server, tools, and client.
  • Third-party tools -- List of companies that provide ASF authoring tools, audio processing, audio/video, cameras, compression technology, MPEG encoding/decoding, and tested capture cards.

The MSDN Online Web Workshop Downloads area is a great source for examples, sample code, and how-to information on HTML-oriented Windows Media Technologies issues such as embedding and sending VBScript or JavaScript events in the ASF stream.

Windows Media Services support options are available.

The MSDN Online Web Workshop Members Helping Members area includes members who specialize in Streaming Media and are willing to help.

There are many third-party companies that specialize in providing Windows Media Technologies services. A list is available at http://www.microsoft.com/windows/windowsmedia/partners/service/default.asp.
