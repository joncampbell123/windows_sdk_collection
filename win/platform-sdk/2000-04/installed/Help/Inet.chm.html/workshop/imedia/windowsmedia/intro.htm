Windows Media Technologies

Updated October 14, 1998

Welcome to the Windows Media Technologies section of the Microsoft MSDN Online Web Workshop! This area provides you with the technical information you need to create and serve streaming media content.

We hope you enjoy this area. You'll also want to visit the Downloads area for demos and code examples you can copy and paste to your own Web site. Send your feedback and suggestions for new or improved content to nswebcom@microsoft.com.

Note   On this site, we've used the symbol to represent an Advanced Streaming Format (ASF) file or stream. Please install the Windows Media Player to view items marked with this graphic.
