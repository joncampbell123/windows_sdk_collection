Information Delivery Enumerated Types

This section defines the enumerated types in the Information Delivery API.

CHANNEL_AGENT_FLAGS Contains the flags that control the channel agent.
CHANNELENUMFLAGS Contains the channel enumerator flags.
CREATESUBSCRIPTIONFLAGS Contains the flags used when creating a subscription.
SUBSCRIPTIONINFOFLAGS Contains the type information about subscriptions.
SUBSCRIPTIONSCHEDULE Contains the values that indicate the update frequency.
SUBSCRIPTIONSTATE Contains the different subscription states.
SUBSCRIPTIONTYPE Contains the different types of subscriptions.
WEBCRAWL_RECURSEFLAGS Contains the flags for the default link crawling agent.
