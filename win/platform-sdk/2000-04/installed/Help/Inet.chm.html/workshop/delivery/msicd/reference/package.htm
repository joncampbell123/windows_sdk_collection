PACKAGE Element

Specifies a Java package or Java application.

Syntax

<PACKAGE
    NAME="name"
    VERSION="a,b,c,d"
>
</PACKAGE>

Attributes

NAME
Required. String value specifying the name of the Java package.
VERSION
String value specifying the major, minor, custom, and build version numbers.

Element Information

Number of occurrences Any number
Parent elements JAVA
Child elements CLASS, IMPLEMENTATION, NEEDSTRUSTEDSOURCE, SYSTEM
File formats supported OSD
Requires closing tag Yes
