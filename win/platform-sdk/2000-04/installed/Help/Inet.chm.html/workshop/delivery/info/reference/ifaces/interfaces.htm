Information Delivery Interfaces

This section describes the interfaces included in the Information Delivery API.

IChannelMgr Provides the ability to add and delete Active Channels and channel categories in the desktop channel bar.
IEnumChannels Enumerates channels.
IEnumItemProperties Enumerates subscription item properties.
IEnumSubscription Allows a client program to enumerate subscription information.
ISubscriptionItem Allows a client program to access the subscription item information.
ISubscriptionMgr Allows a client program to control the subscription manager.
ISubscriptionMgr2 Allows a client program to control the subscription manager.
