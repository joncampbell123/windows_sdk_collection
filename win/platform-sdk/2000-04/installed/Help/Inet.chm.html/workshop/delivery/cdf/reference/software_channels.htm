CDF Extensions for Software Update Channels

This section describes the elements and associated attributes used to create Channel Definition Format (CDF), Microsoft Internet Component Download (MSICD), and Open Software Description (OSD) files for Software Update Channels. This new technology allows users to automatically have new versions of software downloaded and installed from the Web.
