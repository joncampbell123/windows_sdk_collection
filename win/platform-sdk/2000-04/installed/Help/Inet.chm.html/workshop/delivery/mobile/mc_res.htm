Mobile Channels Resources

Preview Release (see note)
Updated: August 6, 1998

In addition to this documentation, Microsoft and other organizations provide a wide variety of sources regarding Mobile Channels. Available Internet resources dealing with Mobile Channels issues are listed below.

Newsgroups

  • http://support.microsoft.com/support/news/
    Ngresults.asp?D=ie&PR=CHS&T1=7d&FR=0&A=T&T=B&S=F
    From this site, you can access the primary newsgroup for Internet Explorer 4.0 Channels, microsoft.public.inetexplorer.ie4.channels.

XMLint

  • http://msdn.microsoft.com/workshop/essentials/inetsdk/inetsdk_map.asp
    The Internet SDK contains XMLint, which validates the syntax and structure of Extensible Markup Language (XML) documents. This tool also guarantees that the XML document you provide loads successfully using the XML ActiveX control that ships with Internet Explorer 4.0.

DBWin32

  • http://search.shareware.com/code/engine/Find?logop=and&cfrom=quick&orfile=True&hits=25&search=DBWin32&category=MS-Windows%28all%29
    DBWin32 enables you to view debugging information gathered from calls to MC.Debug in scripts.

CDF and XML

  • http://www.w3.org/XML
    This site contains articles, specifications, and other information regarding XML.
  • http://msdn.microsoft.com/xml/default.asp
    This section of the Workshop documents how to program using XML and CDF.
  • http://msdn.microsoft.com/xml/notepad/
    These pages in the XML area provide information about XML Notepad, which is a simple prototyping application that allows HTML authors and developers to rapidly build and edit small sets of XML-based data. A free download is also provided.

Internet Explorer 4.0 Channels

  • http://msdn.microsoft.com/workshop/delivery/default.asp
    This (the current) section of the Web Workshop documents how to use and program channels, both as an end user and as a developer.

Mobile Channels

  • http://www.microsoft.com/windowsce/products/download/channels.asp
    This site contains general information regarding the Mobile Channels technology.
