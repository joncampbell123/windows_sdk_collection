Welcome to the Mobile Channels Development Kit Preview Release

Updated: July 17, 1998
New! Downloadable samples

(Please be sure to read the legal information we've provided with this release.)

The Mobile Channels Development Kit for Microsoft® Windows® CE (MCDK) Preview Release is designed to provide Web content developers with the information needed to create mobile channels for the Palm-size PC and other Windows CE-based mobile devices.

This preview release consists of the following topics:

  • An overview of what mobile channels are and how they are used
  • A design guide
  • References for HTML tags and scripts
  • A list of useful resources
  • A trouble-shooting guide
  • Downloadable samples

To view the mobile channels you create, you need Microsoft Internet Explorer 4.0 or later and Microsoft Windows CE Services 2.1. You can install these programs from the compact disc that came with your device, or from the following Web sites:

  • Microsoft Internet Explorer Download at http://www.microsoft.com/ie/download
  • Microsoft Windows CE PC Companions at http://www.microsoft.com/windowsce/pccompanions/wceserv_upgrade.htm
