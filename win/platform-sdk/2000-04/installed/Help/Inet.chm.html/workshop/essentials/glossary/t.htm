  • Tabular Data Control (TDC)
    The TDC is a Microsoft ActiveX™ control that displays data stored in a delimited text file. Using the properties and methods exposed by the control, a Web author can display the data either within tables or within a control found in a form. One of the main features of the TDC is that it brings the filtering and sorting operations to the client side, without requiring any server-side operations.
  • Threading
    In programming, threading is a process that is part of a larger process or program.

    In a tree data structure, a thread is a pointer that identifies the parent node and is used to facilitate traversal of the tree.

    In electronic mail and Internet newsgroups, threading consists of a series of messages and replies related to a specific topic.

  • Transition
    In object-oriented programming, a transition is a type of filter that marks a visual object's passage from one style or state to another. There are two kinds of transition filters: Reveal and Blend. The Reveal Transition reveals what is behind a visual object by using one of 23 transition styles. The Blend transition fades the object in and out of view.
  • TrueType
    TrueTypeis a digital font format, originally designed by Apple Computer, Inc., and now used by both Apple and Microsoft in their operating systems. TrueType fonts offer the highest possible quality on computer screens and printers and include a range of features that make them easy to use.

    The TrueType font technology consists of two components: the TrueType fonts themselves and the TrueType rasterizer, a piece of software built into System 7.x on the Apple Macintosh computers and into the Microsoft Windows operating systems. Both components are necessary to display and print TrueType fonts on a computer system. The interaction between the TrueType fonts, the TrueType rasterizer, and the software program in use determines the appearance of the letterforms in the font.
