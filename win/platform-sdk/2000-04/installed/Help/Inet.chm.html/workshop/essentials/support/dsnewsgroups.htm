Peer-to-Peer Newsgroups for Internet Explorer Development

Updated: November 4, 1998

Microsoft public newsgroups are provided as a forum for peer-to-peer support; we encourage you to use these newsgroups as a medium for finding and communicating with developers who are working with similar technologies. Microsoft Developer Support monitors the microsoft.public.inetexplorer.ie5beta.programming.* newsgroups for common questions, issue trends, and product feedback. Direct one-on-one support with Microsoft personnel in these newsgroups is not guaranteed.

Developer Support regularly documents common issues in Knowledge Base articles and in the support pages here on the Site Builder Workshop site. We highly recommend you search through these sources before using Microsoft's product support services. Your question might already be answered right here in the Workshop! (TIP: When searching the KB on Support Online, search against the products "Internet Explorer Development" or "Internet Client SDK" for programming issues related to Internet Explorer or HTML.)

The following handy table lists all of the peer-to-peer newsgroups hosted on the Microsoft public newserver (msnews.microsoft.com) dedicated to topics relevant to Internet Client development. We recommend you print this table out and carry it with you always.

All newsgroups below reside under the root microsoft.public.inetexplorer.ie5beta.programming.:

Newsgroup Technology
active_desktop
Active Desktop
Desktop items, Shell object model scripting, Webview HTML for shell folders.
activexcontrol
ActiveX Controls
Usage or creation of ActiveX Controls for Internet Explorer.
codedownload
Code Download
Automatic code download of ActiveX controls, Java applets, or other native code components used in the context of Web applications. Also, OSD and software update channels.
components.dhtml_editing
DHTML Editing Component
Reuse of the DHTML Editing Component in applications.
components.webbrowser_ctl
Web Browser Control
Reuse of the Web Browser Control in applications.
data_access
Data Access using Internet Explorer
Databinding in a DHTML Web application, client-side use of RDS, or compatibility with other data access technologies such as ADO or RDO.
dhtml.authoring
HTML Authoring for Internet Explorer
Basic HTML support in Internet Explorer and authoring of HTML pages. This includes non-scripted CSS, layout, tables, and cross-browser compatibility.
dhtml.behaviors
DHTML Behaviors
DHTML Behaviors -- a new HTML extensibility mechanism in Internet Explorer 5.0.
dhtml.scripting
Scripting and Programming DHTML / MSHTML
DHTML object model: programmability of HTML Web pages from any language -- script, VC, VB, etc. -- or ECMAScript (formerly JavaScript) and VBScript language usage inside HTML pages. (Please use dhtml.authoring for non basic HTML questions.)
dhtml.scriptlets
DHTML Scriptlets
Usage or creation of DHTML scriptlets.
misc
Miscellaneous
All other technologies not covered by any of these newsgroups.
multimedia
Multimedia for Internet Explorer
Any of the streaming or interactive media technologies that ship with Internet Explorer or are used in conjunction with Web application development. This includes Microsoft Agent, Micorsoft NetShow, DirectX Media, and the Interactive Music Control.
offline
Offline, Channels, and Information Delivery
Development of web content that exploits the offline and subscription capabilities of Internet Explorer. This includes channel CDF file development, Information Delivery API programming, or other subscription services development questions. (Please use codedownload for OSD and software distribution questions.)
sbnworkshop
Web Workshop Web site
Questions, comments, bug reports, and discussion on the MSDN Online (SBN) Workshop Web site and related Internet Explorer documentation.
urlmonikers
URL Monikers
URL Monikers, URL Open Stream functions, Pluggable Protocols
wininet
Win32 Internet API (WinInet)
Win32 Internet API (WinInet) programming.
xml
XML for Internet Explorer
Usage of XML client-side with Internet Explorer and the authoring of XML data to be used with Internet Explorer. This newsgroup is particularly concerned with Internet Explorer's XML parsing functionality and the XML features that ship with Internet Explorer.

That should cover any issues you might have while developing HTML pages, Web applications, or other content for Internet Explorer. Please visit the Internet Explorer Web site for a complete list of available newsgroups.
