MLang Tutorials

The following is a list of articles that provide examples to demonstrate the functionality of MLang. Familiarity with C++ and COM will help you better understand these examples.

  • How to Enumerate Code Pages and Locales

    This article describes how to use the MLang enumeration objects to create a list of all the code pages or locales your system recognizes. It also describes how to dynamically add them to a pop-up menu to allow users to select their personal preferences.

  • How to Break Text Based on Locale

    This article describes how to use the MLang line-breaking interface to divide text into multiple lines in console-based applications.

  • How to Use Font Linking

    This article describes how to use the MLang font-linking functionality to output text from a wide variety of code pages at once.
