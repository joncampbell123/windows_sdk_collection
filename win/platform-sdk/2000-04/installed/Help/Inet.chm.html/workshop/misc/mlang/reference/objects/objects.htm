MLang Objects

The following articles describe the objects that are exposed by MLang.

Code Page Enumeration The Code Page Enumeration Object is used to retrieve a list of all the code pages the system recognizes.
Conversion The Conversion Object is a conversion engine dedicated to a specified combination of source and destination code pages.
Locale Enumeration The Locale Enumeration Object retrieves a sequence of RFC1766INFO structures.
MultiLanguage The MultiLanguage Object is the primary MLang object. It provides access to all other objects and interfaces implemented by MLang.
Script Enumeration The Script Enumeration Object is used to retrieve a list of all the scripts on the system.
