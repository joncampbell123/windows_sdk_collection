Code Re-signing Tools Download

Updated: July 17, 1997

Before you download and install the code re-signing tools, you must have the following installed on your system:

You'll need the Authenticode 2.0 update to correctly sign your code and properly test it. See the Internet Explorer Security Information and Code Updates page for additional information about this update. You can get this update in two ways:

  • Download Internet Explorer 3.02 with Authenticode 2.0 ; or
  • If you installed Internet Explorer 3.02 before June 13, 1997, download the Authenticode 2.0 update separately.

ActiveX SDK for Internet Explorer

After you've installed the Authenticode 2.0 update and the ActiveX SDK:

Download the code-signing tools update for Authenticode 2.0 (auth2sdk.exe; 287K), which includes complete instructions for re-signing your code using the new timestamp option. To ensure proper installation, you must choose "Save it to disk" (do not choose to open it!) and save the file in your InetSDK\bin directory.

After downloading the SDK update, follow these steps:

  1. Extract the code re-signing tools by going to your InetSDK\bin directory and typing auth2sdk.exe from a command-line prompt.
  2. Review the codesign.doc file in the InetSDK\bin directory for information on how to use the new code re-signing tools.

Tools to help you update your users to Authenticode 2.0

Microsoft is providing you with several options to help update your Internet Explorer for Windows 95 and Windows NT 4.0 users to Authenticode 2.0. We will be using two methods (auto and manual) to update users who hit Microsoft sites. We want to make it easy for you to use either option on your site as well, so we have provided scripts and detailed information on both options.
