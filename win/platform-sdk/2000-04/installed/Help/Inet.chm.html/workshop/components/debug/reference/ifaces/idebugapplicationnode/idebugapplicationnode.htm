IDebugApplicationNode Interface

This interface instantiates a document on demand, maintains a position for the document in the hierarchy, and provides a document context within the tree.

IDebugApplicationNode Methods

Attach Attaches a new application node to a parent node.
Close Closes an application node.
Detach Detaches an application node from its parent.
EnumChildren Enumerates the children of an application node.
GetParent Retrieves the parent of an application node.
SetDocumentProvider Sets the document provided by the IDebugDocumentProvider interface.

Interface Information

Implementation Custom
Inherits from IDebugDocumentProvider
Header and IDL files Activdbg.h, Activdbg.idl
Minimum availability Internet Explorer 4.0
Minimum operating systems Windows 95, Windows NT 4.0
