Internet Explorer 4.0 or 5 Required for HTMLControl Sample

The HTMLControl Visual J++ 6.0 sample requires Internet Explorer 4.0 or greater. Therefore, before you install the sample application you will first need to update your copy of Internet Explorer. Click here to download Internet Explorer.

Netscape Users

If you are using a Netscape browser to view these install pages you will see this message even if Internet Explorer 4 or 5 is already installed on your computer since the detection method uses the navigator.userAgent string. In that case you can ignore this message and...

Download the sample anyway

Download and run the self-extracting setup application (created exactly as I described earlier) that will install the HTMLControl sample application on your computer. After you run the setup application you can start the sample application by clicking the "Visual J++ 6.0 HTMLControl Sample" item in the Program menu on your Start button. You can uninstall the sample application with the "Add/Remove Programs" Control Panel Applet.

The setup application also contains two components that are required for the HTMLControl sample application. These two components are the Microsoft Virtual Machine for Java version 2910 and the WBAddrbook component version 1.0. The components will only be installed on your computer if it does not have current versions. If either of these components are needed you will be asked to approve its publisher digital ID certificate before it can be installed. If needed, these components are installed before the HTMLControl sample application, so you may see their certificates first.
