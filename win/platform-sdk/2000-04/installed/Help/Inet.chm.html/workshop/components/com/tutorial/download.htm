This page contains a link to compressed, self-extracting CAB file containing the complete set of COM Tutorial Samples. Machine versions of this executable file are available for downloading below. In addition to the source code for the samples, this file contains copies of the HTML files that comprise the tutorial for the samples. Note that to compile and run these Win32 code samples, you must have a C++ compiler compatible with Microsoft Visual C++ v. 4 or above installed on your system.

Instructions:

  1. Click the appropriate link below to download the installation program. When asked during the download, specify a temporary directory on your hard drive for the downloaded copy of the installation program.

    ITUTSAMP.EXE (for Win32 on X86 machines, 1.5 MB)
    ATUTSAMP.EXE (for Win32 on Alpha machines, 1.4 MB)

  2. After downloading is complete, run the downloaded copy of the executable and follow the instructions to install the COM Tutorial Samples. During this installation, a destination directory will be requested. The installation program creates a directory structure under the directory you specify. This structure reflects the location of the samples in the installed Platform SDK. For example, if you specify \MSSDK as the destination directory then the samples will be installed under branch \MSSDK\SAMPLES\COM\TUTSAMP.
