Sample Application Install Page

Download and run the self-extracting setup application (created exactly as I described earlier) that will install the HTMLControl custom browser application on your computer. After you run the setup application, you can start it by clicking the "Visual J++ 6.0 HTMLControl Sample" item in the Program menu on your Start button. You can uninstall the sample application with the Add/Remove Programs Control Panel.

There are two <OBJECT> tags on this page that will automatically update two components on your system that are required for the HTMLControl sample application. These two components are the Microsoft Virtual Machine for Java version 5.00.2925 and the WBAddrbook component version 1.0.0. The components will only be downloaded if your computer does not have current versions. If either of these components are downloaded, you will need to approve their publisher's (me) digital ID certificate before it can be installed.
