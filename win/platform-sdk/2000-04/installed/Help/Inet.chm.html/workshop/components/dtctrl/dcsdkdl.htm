Design-time Control SDK Download

The Microsoft Design-time Control SDK will show you how easy it is to create Design-time controls that can make the most complex HTML authoring tasks simple. Microsoft has created a special edition of the Microsoft ActiveX Control Pad that supports Design-time controls: the Microsoft Design-time ActiveX Control Pad. This is a release for developers. You can download this popular ActiveX authoring tool below to try out the sample controls in the SDK and the controls you build yourself.

When you're ready to download the SDK and the special edition of the ActiveX Control Pad, select:

Download the Design-time Control SDK, version 1.0 (self-extracting, 1.1 MB, updated: Feb 4, 1997)

Download the Design-time ActiveX Control Pad for developers (self-extracting, 3.29 MB, updated: Feb 4, 1997)

The files are self-installing, so after saving the files to your hard drive, simply double-click the filename to install.
