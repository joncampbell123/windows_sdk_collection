IBindHost Interface

This interface is implemented by an ActiveX® container that wants controls to do asynchronous data transfers through it.

IBindHost Methods

CreateMoniker Creates a moniker to bind to a URL.
MonikerBindToObject Binds a moniker to an object.
MonikerBindToStorage Binds a moniker to storage.

Interface Information

Implementation Custom
Inherits from IUnknown
Header and IDL files Urlmon.h, Urlmon.idl
Minimum availability Internet Explorer 3
Minimum operating systems Windows 95, Windows NT 4.0

Windows CE

Windows CE Use version 2.12 and later
