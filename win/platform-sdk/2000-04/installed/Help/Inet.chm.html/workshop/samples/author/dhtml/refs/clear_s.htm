This is an example of the clear attribute. These paragraphs are contained within a SPAN object. The image uses the float property to float on the left side of the SPAN. The clear attribute is used to specify whether floating objects are allowed on either side of an object.

Click one of the following buttons to change the clear value for this paragraph. Specifying 'left' sets the paragraph below any floating object on its left side. Specifying 'none' permits floating objects on either side of the paragraph.
