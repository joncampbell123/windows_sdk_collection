scrollHeight Property Sample

This sample will demonstrate the use of the scrollHeight property to retrieve the height of the viewable content.

The scrollHeight property is read-only, allowing you to obtain the height actually needed in the scrolling. Even though the height of this DIV is 200, the height inside the scrolling text box may be less, since the wrapping of the text may mean that not the entire width of the object is used. This dimension may be useful for a variety of reasons; for example, the height of the DIV could be set to the scrollHeight to conserve horizontal space while respecting the set width as a maximum.
