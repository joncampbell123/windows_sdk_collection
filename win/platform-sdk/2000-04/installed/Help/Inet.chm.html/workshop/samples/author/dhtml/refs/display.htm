display Property

This sample demonstrates the use of the "inline", "block", and "none" possible values for the display property.

A SPAN element with a gray background contains the first half of the sample sentence. Modifying the display property of the SPAN changes the flow of the sentence. Click the button that identifies each possible value to change the way the SPAN element is rendered.
