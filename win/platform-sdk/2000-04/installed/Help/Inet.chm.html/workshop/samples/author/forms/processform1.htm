Form Submission Sample

While this page is an Active Server Page, it only contains client-side script. When the page loads, the onload event fires the fnInit function. This function reads the form control names and values from the URL. If you look at the URL in the Microsoft® Internet Explorer Address bar, you can see the form data encoded with the escape method. To decode this information, the unescape method is used once the values have been recovered.
