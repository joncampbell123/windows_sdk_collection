Form Submission Sample

This sample demonstrates the use of the possible value "get" for the METHOD attribute when submitting forms. Enter some text in the following text fields. When the form is submitted, the escape method is used to encode the control values, and the information in the text fields is appended to the URL. The target page parses out the URL to retrieve the control names and values. While the possible value get for the METHOD attribute is deprecated, this is useful for debugging form submissions.
