Microsoft Agent

Microsoft® Agent provides access to a set of services that allow you to support an interactive character from your Web site.

Here is a sample demo using the Microsoft Agent ActiveX® control. Using Internet Explorer 4.0 events and object model, the character reads the text of the page as the user moves his mouse. This sample degrades gracefully under Internet Explorer 3.0.
