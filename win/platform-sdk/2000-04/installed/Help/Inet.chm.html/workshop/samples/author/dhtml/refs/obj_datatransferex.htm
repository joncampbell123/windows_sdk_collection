Example of the dataTransfer Object

This example demonstrates how to use the setData and getData methods of the dataTransfer object, in order to enable the HREF within a link to be dragged. This functionality makes it possible to drop shortcuts into other applications and onto the desktop.

  • To view the HREF of the Test Anchor link, drag it and drop it over the span that says, "Drop the Link Here."
  • To create a shortcut, drag the anchor text to another application or to the desktop.
