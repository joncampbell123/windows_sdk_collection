setTimeout Method

This sample demonstrates the use of the setTimeout method. When the Click to Hide button is clicked, a timeout is set on the window object for a specified number of milliseconds. After that amount of time has elapsed, the function defined as a string is evaluated.

When the Click to Hide button disappears (the display property is set to none), a second button is displayed allowing you to show the first button again.
