INPUT_checkbox Sample

This sample demonstrates the use of the INPUT_checkbox control to allow a user to select multiple choices. In this sample, a mock multiple select question is presented. Notice that by setting the NAME attributes the same, the controls act as a collection. As a collection, the INPUT_checkbox controls can be easily queried in script while maintaining individuality and accepting multiple selections.
