toElement | fromElement | srcElement Sample

This sample examines the srcElement, fromElement, and toElement properties when the onmouseover, onmousemove, and onmouseout events are fired.

First select a mouse event to handle. Then move the mouse cursor over the colored rectangles. As the mouse enters and exits a colored rectangle, the status table to the left of the rectangles displays the tagName and id properties of the element corresponding to the srcElement, fromElement, and toElement properties exposed by the event object at the time the selected event is fired.
