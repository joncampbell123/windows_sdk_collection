Rollover Sample

This sample demonstrates how rollover effects are created using the onmouseover and onmouseout events. Event handlers are set on the document object to process the effects. The style is changed for the SPAN objects when the mouse cursor enters or exits the object. Changing the style provides the rollover effect.
