setInterval Method

The setInterval method invokes a function or line of code everytime the specified amount of time passes. In this sample, a function is called to update the innerHTML property of a SPAN with the current time every 1000 milliseconds, or every second. Click Start Interval to invoke the setInterval method. Click Stop Interval to remove the interval with the clearInterval method.
