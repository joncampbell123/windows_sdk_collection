This example demonstrates how to use the setData and getData methods with the clipboardData object to perform a cut/paste operation through the shortcut menu.

    Steps
  1. If not already selected, select the text, "Cut this...," and avoid extra spaces
  2. Click with the right mouse button, then choose Cut, or choose cut from the Edit menu.
  3. Select some or all of "Paste the Text Here". Click with the right mouse button, then choose Paste, or choose Paste from the Edit menu.
