ForeFront is dedicated to providing the best tools on the market for the Help author — present and future. Because of ForeHelp's database architecture, any Help information, including Microsoft's new HTML Help standard features, can be edited, stored, displayed, and built in any number of formats. ForeHTML Pro is the add-on to ForeHelp that supports HTML Help authoring, and it is shipping NOW! We are pleased to be in the unique position of providing a total HTML Help authoring solution, and WYSIWYG at that, as opposed to providing a conversion solution.

Kathy Wolfskill, Director of Marketing, ForeFront.


ForeFront — ForeHTML Pro is an add-on to ForeHelp that leverages ForeHelp's award-winning, WYSIWYG Help development environment to include complete HTML Help authoring (NOT just a conversion). Switch on-the-fly between WinHelp and HTML-based Help modes via a drop-down box on the format bar, and the display, menu, and dialog box options, and test and build options change according to the selected mode's capabilities. You can even build topics selectively for one mode or another, or mark areas within topics as WinHelp only or HTML only. ForeHelp's reknowned test mode is similarly extended to ForeHTML Pro so that you can quickly and easily view your HTML Help project as you develop it.

ForeHTML Pro's Contents Editor supports all the new HTML Help contents features, such as information types, jumps from book entries as well as topic entries, assigning book and topic graphics from a selection of images, etc.The Window Class Editor lets you assign the tri-pane window as your default, while you can customize navigation buttons, pane backgrounds, and pane appearance attributes. You can, of course, define any number of windows. You are also provided with a number of HTML Help templates if you prefer using a frameset layout. Choose the number of frames, frame layout, navigation controls and images, etc. ForeHTML Pro includes a number of ActiveX controls for advanced features, including a control for advanced support of formatted, HTML pop-ups, another for easy implementation of context-sensitive Help, and another for embedding HTML files inside WinHelp topics, thereby adding any interactive or multimedia elements included in HTML files to WinHelp projects. It further provides easy-to-use interfaces for creating and using related topics, keyword index, framesets, HTML tags, importing HTML files, and scripting. Help authors still have access to ForeHelp's project management Navigator, Grapher, and Reporter tools.
