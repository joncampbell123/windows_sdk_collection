BGSOUND Element | BGSOUND Object

Enables pages with background sounds or soundtracks to be created.

HTML Syntax

<BGSOUND
    BALANCE=n
    CLASS=classname
    ID=value
    LANG=language 
    LOOP=n
    src=url
    TITLE=text
    VOLUME=n
>

Remarks

The BGSOUND element can be used only within the HEAD element.

The BGSOUND element does not require a closing tag.

This element is available in HTML as of Microsoft® Internet Explorer 3.0, and in script as of Internet Explorer 4.0.
