To add the HTML Help ActiveX control to the HTML file

  1. Copy the following Javascript link in your file between the <BODY> start and end tags:

    <a href=javascript:thumb.click()>
    <img src="thumbnail.gif" border=2></a>

    where thumbnail.gif is the name of the thumbnail graphics file you created.

  2. Copy the following HTML Help ActiveX control syntax in your file:

    <OBJECT id=thumb type="application/x-oleobject" classid="clsid:adb880a6-d8ff-11cf-9377-00aa003b7a11">
    <PARAM name="Command" value="Related Topics">
    <PARAM name="Window" value="art window">
    <PARAM name="Item1" value="Topic Title;file.chm::/main_art.gif">
    </OBJECT>

    where art window is the window name you specified in the Define a secondary window to display the main graphic topic and Topic Title;file.chm::/main_art.gif specifies a "friendly" name for the graphics file you are linking to (you can type anything, or leave the default in place), the name of the compiled help file you are working in, and the name of the large graphics file you want to link to.
