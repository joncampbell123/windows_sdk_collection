Index navigation frame example

This frame specifies the attributes for the index (.hhk) file, which appears in the left frame of our sample Web site.

Here is the source code for our index navigation frame file:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2//EN">
<HTML>
<HEAD>
<TITLE>Index example</TITLE>
</HEAD>
<BODY TOPMARGIN=8 LEFTMARGIN=18 BACKGROUND="tile.gif">
<TABLE BORDER=1 BGCOLOR=WHITE WIDTH=204>
<TR>
<TD CLASS=white WIDTH=102 BGCOLOR="white">
<A href="toc.htm" TARGET="left">Contents</A>
</TD>
<TD CLASS=white WIDTH=102 BGCOLOR="white">
<A href="index.htm" TARGET="left">Index</A>
</TD>
</TR>
</TABLE>
<P>
<OBJECT
id=hhctrl
type="application/x-oleobject"
classid="clsid:adb880a6-d8ff-11cf-9377-00aa003b7a11"
width=103%
height=70%>
<PARAM name="Command" value="Index">
<PARAM name="Item1" value="filename.hhk">
</OBJECT>
</p>
