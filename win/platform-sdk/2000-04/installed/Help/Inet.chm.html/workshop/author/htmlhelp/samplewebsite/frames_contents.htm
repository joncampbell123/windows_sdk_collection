Contents navigation frame example

This frame specifies the attributes for the contents (.hhc) file, which is a graphical table of contents that appears in the left frame of our sample Web site.

Here is the source code for our contents navigation frame file:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2//EN">
<HTML>
<HEAD>
<TITLE>Contents example</TITLE>
</HEAD>
<BODY TOPMARGIN=8 LEFTMARGIN=18 BACKGROUND="tile.gif">
<TABLE BORDER=1 BGCOLOR=WHITE WIDTH=204>
<TR>
<TD CLASS=white WIDTH=102 BGCOLOR="white">
<A href="toc.htm" TARGET="left">Contents</A>
</TD>
<TD CLASS=white WIDTH=102 BGCOLOR="white">
<A href="index.htm" TARGET="left">Index</A>
</TD>
</TR>
</TABLE>
<P>
<OBJECT id=hhctrl type="application/x-oleobject" classid="clsid:adb880a6-d8ff-11cf-9377-00aa003b7a11" codebase="file:\\htmlhelp\files\signed\Hhctrl.ocx#Version=4,71,906"
width=103%
height=70%>
<PARAM name="Command" value="Contents">
<PARAM name="Item1" value="filename.hhc">
</OBJECT>
</p>
<TABLE BORDER=1 BGCOLOR=WHITE WIDTH=102>
<TR>
<TD CLASS=white WIDTH=102 BGCOLOR="white">
<A href=javascript:window.top.close()>close</a>
</TD>
</TR>
</TABLE>
</BODY>
