Use the HTML Help Java Applet

Microsoft Corporation

June 23, 1998

The HTML Help Java Applet is a control containing navigation features that you can insert into an HTML file. Use the HTML Help Java Applet with any Web browser that supports Java technology.

The HTML Help Java Applet enables you to add the following navigation features to your HTML files:

  • A table of contents
  • An index
  • Related Topics links

Although the HTML Help Java Applet is not as powerful as the HTML Help ActiveX® control, it does allow you to deliver your help files with navigation features using a browser that is not capable of supporting ActiveX technology.
