HTML Help gets us closer to our goal of creating user assistance that is in the right place at the right time. We want to use both the desktop and the Web as effective media for delivering information to users. With HTML Help, we can author in one language, HTML, and produce material for both environments.

Mary Deaton, President, KNOWware

KNOWware develops custom user assistance solutions for clients worldwide and has already shipped two HTML Help titles and is working on more.

KNOWware has developed training in HTML Help for Microsoft, and sells that same training courseware to the public at its Web site, http://www.kware.com. The course, HTML Help in a Hurry, is a self-guided tour from the beginning of a project to the distribution of a project. Mark Williams, author of HTML Help in a Hurry, delivers on-site training in HTML Help at Microsoft and is available to train at corporate sites around the country. Courseware packages are available for corporate and independent trainers. A site license to freely reproduce the self-study guide is also available. A monthly HTML Help newsletter is sent by KNOWware to everyone who purchases the HTML Help in a Hurry courseware. Customers can also subscribe to a Web site where KNOWware provides tips, tricks, white papers, design ideas, and other support for HTML Help. Consulting, design, and development services are also available from KNOWware.
