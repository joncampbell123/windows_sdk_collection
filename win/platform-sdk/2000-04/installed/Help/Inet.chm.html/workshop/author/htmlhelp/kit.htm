The Official Microsoft HTML Help Authoring Kit

Microsoft Corporation

July 29, 1998

The Official Microsoft HTML Help Authoring Kit, by WexTech Systems Inc., assists help authors, programmers, and HTML experts with mastering the concepts of HTML Help. It also provides practical, step-by-step instructions on how to effectively develop and use HTML Help. For more information, or to read some excerpts from the book, visit the WexTech Web site.

You can order this book today from the Microsoft Press Web site . Updated companion files, information about how to set up the sample programs, and other late-breaking news about this book is also available.
