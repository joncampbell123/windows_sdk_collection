Eon Solutions Ltd. produces hypertext authoring tools for MS Word. Our WinHelp editor, EasyHelp/Web, is one of the leading shareware authoring tools. Although they have moved away from the shareware market, all of their tools are still available from the Internet on a "try-before-you-buy" basis.

Installed with the EasyHTML/Help software is a set of examples which take you step-by-step through the main concepts of Web site authoring. Perfect for both beginners and those already familiar with HTMLHelp.

Another popular Eon Solutions tool is SHG2Map. This converts Windows Help hotspot files (Segmented HyperGraphics) to HTML image maps.

Visit the Eon Solutions Ltd. Web site for more information.
