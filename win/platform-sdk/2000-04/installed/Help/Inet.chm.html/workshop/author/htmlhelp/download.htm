Microsoft HTML Help Download

Microsoft Corporation

March 30, 1999

You can use Microsoft® HTML Help to create and develop help systems and Web sites. The HTML Help ActiveX® control can be used to provide navigation in help systems and on Web sites.

Important! Close any open instances of HTML Help Workshop before reinstalling or updating to a new version. If you do not, the HTML Help ActiveX control may be registered incorrectly.

System requirements:

  • You must set up Microsoft Internet Explorer (3.0 or later) on your computer before using HTML Help. We suggest you use Internet Explorer 5.0. If you haven't already, please download Internet Explorer 5.0.
  • HTML Help requires about 8 MB of free disk space.

End-user license agreement:

The end-user license agreement (EULA) is part of the HTML Help download. You can view the agreement before you download the product.

Product download:

You can download HTML Help Workshop 1.21 (self-extracting .EXE, 4.0 MB), which includes new features, updated documentation, and the English version of the HTML Help Installation and Update package (Hhupd.exe) for redistribution.

Or, you can download a foreign language version, or alpha processor version, of the HTML Help Installation and Update package (Hhupd.exe) 1.21.
