Redistributing HTML Help

Microsoft Corporation

November 4, 1998

Help authors can redistribute the HTML Help Viewer components as needed by redistributing the HTML Help Viewer Installation and Update package (Hhupd.exe). The package consists of a self-extracting executable program that will set up the Help Viewer on a user's computer or update an existing setup of the Help Viewer.

An updated 1.21 version of Hhupd.exe is also now available. The updated version contains bug fixes that affect how compiled help files appear in the Help Viewer. Hhupd.exe is available in 28 languages, for both x86 and alpha platforms. Note that Hhupd.exe will not run on a Windows NT system unless you have administrator privileges.

The Help Viewer requires that Microsoft Internet Explorer (version 3.02 or later) be set up on a user's computer. It is not required that Internet Explorer be used as the system's default browser, or that the Internet Explorer icon be visible on the user's desktop. For more information about redistributing Internet Explorer 5.0, visit the Internet Explorer Administration Kit Web site .

If your users have Internet Explorer 4.0 (or later), they have the 1.0 version of the Help Viewer. To ensure that your users get the latest version of the Help Viewer, you should include Hhupd.exe with your product. Hhupd.exe will never set up an old version of the Help Viewer over a new one.
