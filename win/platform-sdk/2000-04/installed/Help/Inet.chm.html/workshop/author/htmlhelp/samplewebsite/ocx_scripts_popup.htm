Example: Create a pop-up message

Using the HTML Help ActiveX control, you can create a pop-up message that appears when a user clicks a specific word, phrase, or graphic in a topic. A simple JavaScript link passes all the necessary parameters to the HTML Help ActiveX control.

This example works in both compiled help (.chm) files and uncompiled HTML files.

To insert the HTML Help ActiveX Control into a file

You can insert the control manually or by using the HTML Help ActiveX control Wizard. This is an example of the <OBJECT> tag code:

<OBJECT id=HHCTRL type="application/x-oleobject"
classid="clsid:adb880a6-d8ff-11cf-9377-00aa003b7a11"
>
</OBJECT>

To insert the JavaScript link into a file

The following example calls the TextPopup method of the HTML Help ActiveX control whose ID is HHCTRL and displays the variable MyText:

<A href=javascript:hhctrl.textpopup(mytext,"verdana,10",9,9,-1,-1)
Title="Example of the TextPopup method.">
Click to see a pop-up window.</A>

A sample of the resulting link is shown below:

Click to see a pop-up window

In this example, the variable MyText contains the actual text that appears in the pop-up window. You can embed multiple variables in your HTML file or store them in a text file.

The other settings specify font face and size (Verdana, 10 point), left and right margins (9,9), and the foreground and background colors (-1, -1). The Title attribute specifies the text that displays when a user hovers the mouse over the hyperlink. Title is similar to the ALT atribute of the <IMG> tag.

Notes

  • Margin values are expressed in pixels.
  • Colors are expressed as RGB values. In HTML Help version 1.1, we recommend that you use the default value of -1 for both the text and background color.

Text formatting examples

You can select alternate values for the margin and color values. A conversion table will soon be available to convert RGB values. Here are some examples of pop-up windows with formatted text:

  • The default pop-up fonts and colors.
  • The side margin at a value of 99 pixels.
  • The top margin at a value of 99 pixels.
  • The text color at a value of 8855416.
  • The background color at a value of 0.

To embed the pop-up text variables in an HTML file

The text variables for each pop-up window can be embedded in the HTML file using the <SCRIPT> tag. You can store an unlimited number of variables using this method.

This example shows two variables and their values:

<script>
Text1="The text for the first pop-up."
Text2="The text for the second pop-up."
</script>

To reference the pop-up text variables in a text file

The text variables for all pop-up messages can be stored in one text file with the .js file name extension. This enables you to store the pop-up text messages from several HTML pages in one location. This also enables you to globally define the font face and font size to be used for pop-up messages.

To do this, you need to insert the <OBJECT> tag and the Javascript code between the <HEAD> start and end tags of each HTML file that contains pop-ups. This code contains the link to the master text file ("terms.js" in this example), and also contains an error message that will appear if the master text file cannot be found. Add the code as follows:

<OBJECT id=HHCTRL type="application/x-oleobject"
classid="clsid:adb880a6-d8ff-11cf-9377-00aa003b7a11" >
</OBJECT>

<SCRIPT language=jscript
src="terms.js">
document.write("Included JScript file not found");
</SCRIPT>

Next, create a text file with the .js file name extension. Make sure to give it the same name as the file you specified in the JavaScript tag. The format of the text file is as follows:

popfont="Verdana,10"
Text1="The text for the first pop-up."
Text2="The text for the second pop-up."

where popfont is the name of the variable that defines the font face and font size for all pop-up messages.

The JavaScript code used for each link is similar to the first example, except a variable is specified in place of an actual font face and font size.

<A href="javascript:hhctrl.textpopup(text1,popfont,9,9,-1,-1)"
Title="Click for pop-up definition">Word to be defined</A>

If you want, you can substitute the link text with an image by using the <IMG> tag. You can also trigger a pop-up window from an image map link.

To trigger a pop-up window from an image map

  1. Insert the <OBJECT> tag into an HTML file.
  2. Insert the HTML code for the image, the image map, and a script for the text variables. You can store the text variables in a text (.js) file.

    The image

    <img src="test.gif" usemap="#test" BORDER=0 WIDTH=216 HEIGHT=216>

    The image map

    For each defined area of the image map, add a JavaScript link that calls the TextPopup method of the HTML Help ActiveX control.

    <MAP NAME="test">

    <AREA SHAPE=RECT COORDS="4,2,108,103" A A href="javascript:hhctrl.textpopup(square1,popfont,9,9,-1,-1)" Title="Square 1">

    <AREA SHAPE=RECT COORDS="117,6,212,104" href="javascript:hhctrl.textpopup(square2,popfont,9,9,-1,-1)" Title="Square 2">

    <AREA SHAPE=RECT COORDS="3,111,105,213" href="javascript:hhctrl.textpopup(square3,popfont,9,9,-1,-1)" Title="Square 3">

    <AREA SHAPE=RECT COORDS="114,113,211,210" href="javascript:hhctrl.textpopup(square4,popfont,9,9,-1,-1)" Title="Square 4"> </MAP>

    The text variables

    <SCRIPT Language=JavaScript>
    popfont="Verdana,10"
    square1="Welcome to Square 1!"
    square2="This is Square 2!"
    square3="Welcome to Square 3!"
    square4="Square 4 welcomes you!"
    </SCRIPT>
