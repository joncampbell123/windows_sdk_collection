Microsoft HTML Help Download

Microsoft Corporation

April 6, 1999

Download HTML Help Workshop 1.21 (self-extracting .EXE, 4.0 MB). The HTML Help Workshop includes new features, updated documentation, and the English version of the HTML Help Installation and Update package (Hhupd.exe) for redistribution.

Download the HTML Help Installation and Update Package (Hhupd.exe) 1.21. The foreign language and alpha processor versions of Hhupd.exe are also available here. This file will update HTML Help to the latest version for any of 28 languages. Also downloadable from this page is the Alpha processor version of htmlhelp.lib, the library file for use with the HTML Help API on the Alpha platform.

Download HTML Help 1.21 documentation. The documentation includes: the main help file for HTML Help Workshop, the HTML Help ActiveX Control Reference, and the HTML Help API Reference.

Download help for the HTML Help Viewer. The help file contains generic topics on how to use the HTML Help Viewer.
