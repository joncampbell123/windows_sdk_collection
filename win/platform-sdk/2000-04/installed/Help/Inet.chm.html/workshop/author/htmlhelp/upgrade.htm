Microsoft HTML Help Download

Microsoft Corporation

Last updated: February 26, 1998

You can use Microsoft® HTML Help to create and develop help systems and Web sites. The HTML Help ActiveX® control can be used to provide navigation in help systems and on Web sites.

Caution: Users upgrading from HTML Help version 1.0

Do not try to run the Setup program directly over the Web. To set up HTML Help Workshop, download the version 1.1 files, save them to a local drive, and then restart your computer before running Setup.

System requirements:

  • Authoring using HTML Help requires that Microsoft Internet Explorer 3.0 or later be set up on your computer. We suggest you use Internet Explorer 5.0. If you haven't already, please download Internet Explorer 5.0 .
  • HTML Help requires about 8 MB of free disk space.
