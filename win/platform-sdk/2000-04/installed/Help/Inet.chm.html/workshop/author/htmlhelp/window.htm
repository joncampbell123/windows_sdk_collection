Create Custom Help Windows

Microsoft Corporation

June 23, 1998

You can create custom windows to display help topics instead of, or in addition to, the Help Viewer or a custom frameset. You can define additional three-pane windows for the Help Viewer with custom window definitions, or define one-pane secondary windows. Secondary windows can include:

  • Unique window types for the title bar
  • Button options for the toolbar
  • On-screen size and position of the window
  • Customizations of the Navigation pane for the default help window
  • Window styles

Windows created by HTML Help are controlled by the program that calls HTML Help. This enables the HTML Help window to stay on top of its parent program but not be on top of any other program you switch to. It also ties the window to the actions of the program.

For example, if you minimize the program window, the HTML Help window is minimized too. If the program closes, the HTML Help window also closes without requiring any action from the program. In addition, because the program created the HTML Help window, it can change the position and properties of that window without affecting the help of any other program.
