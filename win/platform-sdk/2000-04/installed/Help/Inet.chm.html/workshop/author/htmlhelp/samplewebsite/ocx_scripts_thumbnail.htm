Example: Use a thumbnail graphic to link to a large graphics file

You can use the HTML Help ActiveX control to link to a large graphic from a small "thumbnail" representation. When a user clicks a thumbnail graphic, the large graphic appears in a secondary window, leaving the main help topic in its original state. This example is based on the Related Topics command.

The five steps of the process are as follows:

  1. Create a thumbnail graphic.
  2. Define a secondary window to display the main graphic.
  3. Add each graphics file to your project (.hhp) file.
  4. Add the HTML Help ActiveX control to your HTML file.
  5. Compile your help project.

Note

  • You can only use this example with a compiled help (.chm) file.
