HTML Help Documentation

Microsoft Corporation

April 6, 1999

The HTML Help documentation contains two basic components.

The first is the HTML Help Authoring Guide, which is an online document designed to provide designers and help authors with the information they need to use HTML Help and its components.

The second is the HTML Help reference section, which provides advanced information to help developers and help authors. You can use the reference topics to learn more about the HTML Help ActiveX® control and the HTML Help API.

To download the entire documentation set, you must click all three of the links below and save the compiled help (.chm) files to your hard disk. All three files must be copied to the same location for the entire documentation set to appear correctly:

  • The HTML Help Authoring Guide (Htmlhelp.chm)
  • The HTML Help ActiveX control reference (Hhaxref.chm)
  • The HTML Help API reference (Api.chm)

Help for the HTML Help Viewer is also available. It contains all the information users need to know about using the standard HTML Help viewer.

In addition to this documentation, information on developing accessible software, Web site designs, and HTML content is available on the Microsoft Accessibility and Disabilities Web site.

Note

  • If you have HTML Help Workshop set up and want to use these files with the workshop, you need to copy them over the installed compiled help files. By default, help files are installed on your hard disk in the following location during Setup:
    C:\Windows\Help.
