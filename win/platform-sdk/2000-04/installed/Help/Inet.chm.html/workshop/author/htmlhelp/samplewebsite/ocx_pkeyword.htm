Keyword

Use the Keyword property to insert keywords in a target HTML file. When you create a Keyword link (KLink) in a file, the link searches for all target files that contain the specified keyword. In a compiled help (.chm) file, keywords are also added to the index.

Applies To

Possible Values

Syntax Description Example Notes
Param name="KLink" value="<Enter Text for KLink>" Specifies the keyword that will be used to locate target topics when a user clicks a KLink jump in a compiled help file. ... The value for this property must match the text specified in the Item2 property of the KLink.
