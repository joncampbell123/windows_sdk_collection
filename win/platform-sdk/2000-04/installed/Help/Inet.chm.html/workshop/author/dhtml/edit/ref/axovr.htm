ActiveX Control API Reference

Microsoft Corporation

February 19, 1999

The design approach of the DHTML Editing control is to expose existing editing functionality to Visual Basic® and Web script authors. The DHTML Editing control does not add any editing functionality itself.

The functionality exposed by the control is implemented in one of the following ways:

  • ActiveX Control Methods
  • ActiveX Control Properties
  • ActiveX Control Events
  • ActiveX Control Command IDs
