COLOR Attribute | color Property

Sets or retrieves the value of the color applied with the filter.

Syntax

HTML { filter:filterName (COLOR = sColor ...) }
Scripting object.filters.filterName.color [ = sColor ]

Possible Values

sColor String that specifies the color value.

The property is read/write with no default value.

Remarks

Color is expressed in #RRGGBB format, where RR is the red hexadecimal value, GG is the green hexadecimal value, and BB is the blue hexadecimal value. For more information about the range of color values supported by Microsoft® Internet Explorer 4.0 and later, see the Color Table.

The following table describes the effect of the color property when applied to different filters.

chroma filterSpecifies the color applied to the chromakey transparency.
dropShadow filterSpecifies the color of the drop shadow effect.
glow filterSpecifies the color of the radiance applied to the object.
mask filterSpecifies the color that the transparent regions are painted.
shadow filterSpecifies the color of the shadow effect.
