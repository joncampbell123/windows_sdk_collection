Basic Procedures for Using HTML Help Workshop

Microsoft Corporation

Updated June 10, 1999

The following list describes the basic procedures for using Microsoft® HTML Help Workshop.

To open HTML Help Workshop

On the Start menu, point to Programs, point to HTML Help Workshop, and then click HTML Help Workshop.

To close HTML Help Workshop

On the File menu, click Exit.

To display or hide the toolbar

On the View menu, click Toolbar.

To display or hide the status bar

On the View menu, click Status Bar.

To display HTML Help Messages

On the View menu, click HTML Help Messages.

To arrange HTML Help Workshop windows or icons

On the Window menu, click Cascade, Tile Horizontally, Tile Vertically, or Arrange Minimized Windows.

To view a file

On the File menu, click Open.

To change the name or location of a file

On the File menu, click Save File As.

To save all open files

On the File menu, click Save All Files.

To close a file

On the File menu, click Close File.

To close all open files

On the File menu, click Close All.

To close a help project

On the File menu, click Close Project.

To save a help project

On the File menu, click Save Project.

To change the name or location of a help project

On the File menu, click Save Project As.

To set help project preferences

On the File menu, click Preferences, and then click the General tab.

To set contents file preferences

On the File menu, click Preferences, and then click the Contents tab.

To set index file preferences

On the File menu, click Preferences, and then click the Index tab.

To edit an existing project file

On the File menu, click Open. In the Files of type box, click Project files (*.hhp), and then locate the project file.

To close an open project file

On the File menu, click Close Project.

To save an open project file

On the File menu, click Save Project.

To rename an open project file or save it in a new location

On the File menu, click Save Project As.
