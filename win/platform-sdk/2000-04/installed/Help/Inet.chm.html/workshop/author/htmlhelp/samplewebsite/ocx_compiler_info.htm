Compiler Information

Purpose

Inserts KLink keywords and ALink names in a target HTML file. This allows the HTML file to be a target of an ALink or KLink from another file. This command can be used only with a compiled help (.chm) file.

Syntax

<param name="Keyword" value="keyword1">
<param name="Keyword" value="keyword2">
<param name="ALink Name" value="ALink1">
<param name="ALink Name" value="ALink2">
Property Property Description
Keyword Specifies the text of an individual KLink keyword. Each instance must have its own individual <PARAM> tag.
ALink Name Specifies the text of an individual ALink name. Each instance must have its own individual <PARAM> tag.

Example

<Object type="application/x-oleobject" classid="clsid:1e2a7bd0-dab9-11d0-b93a-00c04fc99f9e">
<param name="Keyword" value="nutrition">
<param name="Keyword" value="protein">
<param name="ALink Name" value="nutrition">
<param name="ALink Name" value="protein">
</OBJECT>

Comments

  • To create a target topic using KLink keywords or ALink names, open the HTML file you want to set as a target in HTML Help Workshop. Click the Edit menu, and then click Compiler information. You will be prompted for KLink keywords or ALink names depending on which tab you select.
  • To create ALink and Klink jumps in an HTML file to target topics, use the ALink (uses ALink names) and KLink (uses KLink keywords) commands.
  • Compile-time commands use a different CLASSID value than run-time commands.
