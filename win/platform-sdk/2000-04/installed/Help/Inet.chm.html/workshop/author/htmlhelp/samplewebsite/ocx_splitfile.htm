Split file

Purpose

Splits a single HTML file with multiple topics into multiple topic files during compilation. The Split File command behaves the same way that a page break behaves in a Rich Text Format (.rtf) file. The split occurs wherever an instance of the HTML Help ActiveX control has been inserted.

The Split File command copies the basic document tags, such as the <DOCTYPE>, <HTML>, <HEAD>, and <BODY> tags from the master HTML file.

The split HTML files do not appear in the [FILES] section of the project (.hhp) file. To create links to these files in any HTML file or in your table of contents, refer to the file names specified in Split File. These HTML files are accessible only from the master HTML file until after compilation.

This command can be used only with a compiled help (.chm) file.

Syntax

<PARAM name="New HTML File" value="file name">
<PARAM name="New HTML Title" value="file title">
Property Property Description
New HTML file Specifies the name of the HTML file that will result from the split. Use this file name to create links and contents entries to this topic.
New HTML title Specifies the title of the HTML file that will result from the split.

If you do not specify a title, the title from the master document is copied.

Example

This example shows how one master HTML file can be split into four separate files using three instances of the HTML Help ActiveX control.

Note that the Split File command does not require an ID attribute.

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">
<HTML>
<HEAD>
<META HTTP-EQUIV="Content-Type" Content="text-html;
charset=Windows-1252">
<title>Split File Test</title>
</HEAD>

<BODY BGCOLOR=#FFFFFF TEXT=#000000>

<p>
This is the master file that stores multiple topics. Each topic is split into an individual HTML file during compilation.
</p>

<p>
You can easily link to any topic within this master HTML file by referencing the file name specified in the Split File command.
<ul>
<li>
<a href="/workshop/author/htmlhelp/samplewebsite/file_1.htm">link to topic 1</a> <li>
<a href="/workshop/author/htmlhelp/samplewebsite/file_2.htm">link to topic 2</a> <li>
<a href="/workshop/author/htmlhelp/samplewebsite/file_3.htm">link to topic 3</a> </li>
</ul>

<p>

Comments

  • You can include the master HTML file in your project file. All text before the first instance of the control will appear in the master file after compilation. Any text that occurs after an instance of the control is removed and placed in the file specified for that instance of the HTML Help ActiveX control.
  • Compile-time commands use a different CLASSID attribute than run-time commands.
