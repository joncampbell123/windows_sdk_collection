Tools Supporting Dynamic HTML

Microsoft Corporation

Updated: October 30, 1997

Microsoft FrontPage 98 has a range of features that let you take advantage of the benefits of Dynamic HTML without having to program the Dynamic HTML object model. You can create text animations, dynamic outlines that expand and collapse, and page transitions without programming. For details and demos, visit the FrontPage Web site .

We've also compiled, for your reference, a list of third-party tools that will help you incorporate Dynamic HTML effects into your Web pages. (See Microsoft's announcement dated June 24, 1997.)

Please note that the links below point to servers that are not under Microsoft's control. See Microsoft's official statement regarding other servers.
