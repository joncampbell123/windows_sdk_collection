HTML Help Viewer Topics

Microsoft Corporation

Updated: April 6, 1999

The HTML Help Viewer help file contains all the information your users need about using the Help Viewer. It includes detailed instructions for navigating a help file, conducting effective searches, printing topics, customizing the Help Viewer, and more.

You can decompile this help file, revise the topics to conform to your own styles and guidelines, and include them in your main help system.

The Help Viewer topics have been tested against the 1.2 release of HTML Help Workshop.

Include the HTML Help Viewer topics in your help files.
