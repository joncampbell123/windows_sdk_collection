ALink Name

Use the ALink Name property to insert Associative link (ALink) names in a target HTML file. To link to a target file, the ALink must be added to the file you want to link from.

Applies To

Compiler Information

Possible Values

Syntax Description Example Notes
Param name="ALink" value="ALink name" Specifies the keyword that will be used to locate target topics when a user clicks an ALink jump in a compiled help file. ... The value for this property must match the text specified in the Item2 property of the ALink.
