Microsoft FrontPage 2000 Server Extensions Resource Kit (SERK)

Microsoft Corporation

Updated April 15, 1999

The Microsoft FrontPage 2000 Server Extensions Resource Kit (SERK) is an administrator's guide to understanding, installing, and maintaining the FrontPage Server Extensions on Web servers running any of the supported platforms. The SERK is made up of a set of HTML-based documents that have been packaged together in a self-extracting executable. To view the SERK you must be running a 3.0 or greater version of Netscape Navigator or Microsoft Internet Explorer.

Download Details

  • Download the SERK and save the file to a location on your hard drive.
  • You may then extract the files by double clicking on the fp2kserk.exe and selecting a location to which the files should be extracted.
  • To view the SERK, open the default.htm file.
