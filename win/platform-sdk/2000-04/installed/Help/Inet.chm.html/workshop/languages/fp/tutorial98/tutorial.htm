FrontPage 98 Online Tutorial

What You Will Learn

This tutorial will show you how easy it is to use Microsoft FrontPage to get a new Web site up and running. The three lessons that follow will introduce you to Microsoft FrontPage using easy to follow, step-by-step procedures.

  • Lesson 1: Building a New Web Site

    In Lesson 1, you will learn how to use the FrontPage Explorer to create a four-page Web site with professionally  designed Web graphics and functional navigation bars.  You will also learn how to edit the pages by adding text, images, formatted lists, and hyperlinks using the FrontPage Editor.

  • Lesson 2: Web Page Design in the FrontPage Editor

    In Lesson 2, you will learn how to insert files on pages, collect feedback from visitors to your site, make image maps from pictures, add a table, insert a list, and add a scrolling marquee using the FrontPage Editor.

  • Lesson 3: Publishing Your FrontPage Web

    In Lesson 3, you will return to the FrontPage Explorer, where you will test your hyperlinks, check spelling across all Web pages, find and replace text on pages, view and complete Web tasks, and publish your FrontPage Web on the World Wide Web.
