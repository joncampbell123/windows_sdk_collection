                    ------------------------------------
                    3Com NetBIOS Protocol Error Messages

                                 %VER 1.1
                    ------------------------------------



INTRODUCTION
============

This document discusses the error messages that may be displayed by
the 3Com NetBIOS Protocol (NBP).


ERROR MESSAGES
==============

NBP0001: Initialization failure

This is a general purpose message that will be issued by NBP after any
other error messages.  If this is the only message that is displayed,
there is some kind of internal error.  Call your 3Com representative.

NBP0002: Syntax error in PROTOCOL.INI - Invalid Parameter Value

There is an error in the PROTOCOL.INI file.  The line in error (or an
approximation thereof) will be displayed following this error message.
The parameter on the right hand side of the equals sign is invalid for
this keyword.  Check the PROTOCOL.INI file against the installation
documentation provided with NBP.

NBP0003: Syntax error in PROTOCOL.INI - Unrecognized Keyword

There is an error in the PROTOCOL.INI file.  The line in error (or an
approximation thereof) will be displayed following this error message.
The keyword specified is invalid.  Check the PROTOCOL.INI file against
the installation documentation provided with NBP.

NBP0004: No PROTOCOL.INI section for NBP

The PROTOCOL.INI file does not contain a section with the statement:

    drivername = nbp$

which identifies information for the NBP driver.  This section is
required for installation.  See the installation instructions.

NBP0005: No BINDINGS specified for NBP

The section in PROTOCOL.INI for NBP must contain a line specifying
which network adapter (MAC) driver to bind with.  For example:

    bindings = etherlink/mc

See the installation instructions.

NBP0006: Protocol Manager not installed

NBP requires that the Protocol Manager be loaded prior to itself in
the CONFIG.SYS or CONFIG.OS2 file.  The Protocol Manager driver is
called either PROTMAN.DOS or PROTMAN.OS2 based on the station
operating system.  See your installation instructions.

NBP0007: Insufficient Memory for Configuration Requested

The configuration requested requires more memory than is available.
Edit the PROTOCOL.INI file to reduce the memory requirements (for
example, decrease the number of sessions, or the size of the receive
cache), remove some other driver from your configuration, or get more
memory.
